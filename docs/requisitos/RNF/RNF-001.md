## Requisitos

### RNF-001.1 — Cifrado de datos en tránsito

Toda la comunicación entre clientes, servidores y servicios externos debe realizarse mediante conexiones seguras HTTPS utilizando TLS 1.2 o superior.

### RNF-001.2 — Protección de credenciales

Las contraseñas de los usuarios deben almacenarse mediante algoritmos de hashing seguro, evitando el almacenamiento en texto plano.

### RNF-001.3 — Protección de información sensible

La información sensible almacenada en la plataforma debe protegerse mediante mecanismos de seguridad adecuados para prevenir accesos no autorizados.

### RNF-001.4 — Gestión segura de sesiones

Las sesiones autenticadas deben contar con mecanismos de expiración y validación para minimizar riesgos de acceso indebido.

### RNF-001.5 — Protección contra ataques comunes

La aplicación debe implementar medidas de protección contra vulnerabilidades comunes como inyección SQL, XSS y CSRF.

### RNF-001.6 — Gestión de secretos

Las claves, tokens y credenciales de servicios externos deben almacenarse mediante variables de entorno y nunca incluirse directamente en el código fuente.

### RNF-001.7 — Registro de eventos de seguridad

El sistema debe registrar eventos relevantes de autenticación, autorización y acceso para facilitar auditorías y monitoreo.

### RNF-001.8 — Actualización de dependencias

Las bibliotecas y dependencias utilizadas deben mantenerse actualizadas para reducir riesgos asociados a vulnerabilidades conocidas.
