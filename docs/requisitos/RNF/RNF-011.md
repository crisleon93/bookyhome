## Requisitos

### RNF-011.1 — Copias de seguridad

La plataforma debe generar respaldos periódicos de la información almacenada.

### RNF-011.2 — Restauración de datos

Deben existir procedimientos documentados para restaurar información en caso de incidente.

### RNF-011.3 — Protección ante pérdida de datos

Los mecanismos de respaldo deben minimizar el riesgo de pérdida permanente de información.

### RNF-011.4 — Recuperación de servicios

La plataforma debe disponer de procedimientos para restablecer servicios afectados por fallos críticos.

### RNF-011.5 — Verificación de respaldos

Los respaldos deben verificarse periódicamente para garantizar su integridad.

### RNF-011.6 — Continuidad del negocio

Los procesos de recuperación deben priorizar la disponibilidad de las funcionalidades críticas del sistema.
