# RF-021 — Gestión de usuarios

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-021 |
| Nombre | Gestión de usuarios |
| Módulo | Administración |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir a los administradores consultar, actualizar y gestionar la información de los usuarios registrados en la plataforma.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| user_id | UUID | Sí |
| status | Texto | No |
| role | Texto | No |

---

## Proceso

1. El administrador accede al módulo de usuarios.
2. Consulta la información registrada.
3. Selecciona un usuario.
4. Realiza modificaciones autorizadas.
5. El sistema valida la operación.
6. Se actualiza la información correspondiente.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Operación exitosa | 200 | Usuario actualizado |
| Usuario inexistente | 404 | No encontrado |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| GET | /api/v1/users |
| GET | /api/v1/users/{id} |
| PUT | /api/v1/users/{id} |

---

## Reglas de negocio

- RN-001: Solo administradores pueden gestionar usuarios.
- RN-002: Toda modificación debe registrarse en auditoría.
