# RF-015 — Gestión de perfil de usuario

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-015 |
| Nombre | Gestión de perfil de usuario |
| Módulo | Usuarios |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir que los usuarios actualicen la información de su perfil.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| full_name | Texto | No | Máximo 255 caracteres |
| phone | Texto | No | Formato válido |
| profile_image | URL | No | Formato válido |

---

## Proceso

1. El usuario accede a su perfil.
2. Modifica la información.
3. El sistema valida los datos.
4. Se actualiza el registro correspondiente.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Actualización exitosa | 200 | Perfil actualizado |
| Error validación | 422 | Datos inválidos |

---

## Endpoints asociados

| Método | Ruta | Auth requerida | Descripción |
|----------|----------|----------|----------|
| GET | /api/v1/profile | Sí | Consultar perfil |
| PUT | /api/v1/profile | Sí | Actualizar perfil |

---

## Reglas de negocio

- RN-001: Solo el propietario puede modificar su perfil.
- RN-002: Los cambios deben validarse antes de almacenarse.
