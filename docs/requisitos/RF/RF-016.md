# RF-016 — Gestión de favoritos

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-016 |
| Nombre | Gestión de favoritos |
| Módulo | Favoritos |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir guardar publicaciones como favoritas para consultas posteriores.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| book_id | UUID | Sí | Debe existir |

---

## Proceso

1. El usuario selecciona un libro.
2. Marca la opción favorito.
3. El sistema registra la asociación.
4. El libro aparece en la lista de favoritos.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Favorito agregado | 201 | Registro creado |
| Favorito eliminado | 200 | Registro eliminado |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| POST | /api/v1/favorites |
| DELETE | /api/v1/favorites/{id} |
| GET | /api/v1/favorites |

---

## Reglas de negocio

- RN-001: No se permiten favoritos duplicados.
- RN-002: Solo usuarios autenticados pueden utilizar favoritos.
