# RF-020 — Moderación de publicaciones

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-020 |
| Nombre | Moderación de publicaciones |
| Módulo | Moderación |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir a los administradores revisar y gestionar publicaciones reportadas.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| report_id | UUID | Sí |
| action | Texto | Sí |

---

## Proceso

1. El administrador consulta los reportes.
2. Analiza la publicación reportada.
3. Selecciona una acción.
4. El sistema actualiza el estado correspondiente.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Moderación exitosa | 200 |
| Reporte inexistente | 404 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| GET | /api/v1/reports |
| PATCH | /api/v1/reports/{id} |

---

## Reglas de negocio

- RN-001: Solo administradores pueden moderar publicaciones.
- RN-002: Toda acción de moderación debe quedar registrada.
- RN-003: Las publicaciones suspendidas dejan de mostrarse en el catálogo.
