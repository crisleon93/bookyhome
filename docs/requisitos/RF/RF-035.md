# RF-035 — Notificaciones de novedades

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-035 |
| Nombre | Notificaciones de novedades |
| Módulo | Notificaciones |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe generar notificaciones relacionadas con nuevas publicaciones, promociones y eventos relevantes para los usuarios.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| notification_type | Texto | Sí |
| user_id | UUID | Sí |
| content | Texto | Sí |

---

## Proceso

1. Se genera un evento dentro de la plataforma.
2. El sistema identifica usuarios relacionados.
3. Se crea la notificación correspondiente.
4. La notificación se almacena.
5. El usuario la visualiza desde el módulo de notificaciones.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Notificación creada | 201 |
| Consulta exitosa | 200 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| GET | /api/v1/notifications |
| POST | /api/v1/notifications |

---

## Reglas de negocio

- RN-001: Las notificaciones deben asociarse a eventos válidos.
- RN-002: Solo el destinatario puede consultar sus notificaciones.
- RN-003: Las notificaciones pueden marcarse como leídas.
- RN-004: El historial de notificaciones debe conservarse.
