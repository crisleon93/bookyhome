# RF-011 — Comunicación con vendedor

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-011 |
| Nombre | Comunicación con vendedor |
| Módulo | Mensajería |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir la comunicación entre usuarios y negocios mediante mensajes asociados a publicaciones.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| publication_id | UUID | Sí | Debe existir |
| message | Texto | Sí | No vacío |

---

## Proceso

1. El usuario accede a una publicación.
2. Selecciona contactar vendedor.
3. Escribe el mensaje.
4. El sistema valida la información.
5. El mensaje se almacena.
6. Se crea o actualiza la conversación.
7. El vendedor recibe la notificación correspondiente.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Mensaje enviado | 201 | Conversación actualizada |
| Error de validación | 422 | Datos inválidos |

---

## Endpoints asociados

| Método | Ruta | Auth requerida | Descripción |
|----------|----------|----------|----------|
| POST | /api/v1/messages | Sí | Enviar mensaje |
| GET | /api/v1/messages/{conversationId} | Sí | Consultar conversación |

---

## Reglas de negocio

- RN-001: Solo usuarios autenticados pueden enviar mensajes.
- RN-002: Toda conversación debe asociarse a una publicación.
- RN-003: Los mensajes deben conservarse en el historial.
