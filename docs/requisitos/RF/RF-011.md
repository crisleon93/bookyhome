# RF-011 — Comunicacion con vendedor

---

## Identificacion

| Campo | Valor |
|---------|---------|
| ID | RF-011 |
| Nombre | Comunicacion con vendedor |
| Modulo | Mensajeria |
| Prioridad | Media |
| Estado | Alcance final |
| Fecha | Febrero 2026 |

---

## Descripcion

El sistema debe permitir que un comprador contacte a la tienda o vendedor responsable de una publicacion para resolver dudas sobre disponibilidad, estado del libro, entrega o condiciones de compra.

Esta funcionalidad hace parte del alcance final del producto. Puede implementarse inicialmente como contacto externo o enlace directo, y evolucionar a mensajeria interna.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| id_libro | Entero | Si | Debe existir |
| id_tienda | Entero | Si | Debe existir |
| mensaje | Texto | Si | No vacio, longitud maxima definida |
| id_usuario | Entero | Si | Usuario autenticado |

---

## Proceso

1. El comprador accede al detalle de un libro.
2. Selecciona la opcion de contactar al vendedor.
3. El sistema identifica la tienda asociada al libro.
4. El comprador escribe o confirma el mensaje.
5. El sistema registra o envia el mensaje.
6. El vendedor recibe la consulta o puede verla desde su panel.

---

## Salidas

| Escenario | Codigo HTTP | Respuesta |
|------------|------------|------------|
| Mensaje enviado | 201 | Confirmacion de envio |
| Usuario no autenticado | 401 | Se solicita iniciar sesion |
| Libro o tienda no existe | 404 | Recurso no encontrado |
| Error de validacion | 422 | Datos invalidos |

---

## Endpoints objetivo

| Metodo | Ruta | Auth requerida | Descripcion |
|----------|----------|----------|----------|
| POST | /mensajes | Si | Enviar mensaje al vendedor |
| GET | /mensajes | Si | Listar conversaciones del usuario autenticado |
| GET | /mensajes/{id_conversacion} | Si | Consultar detalle de una conversacion |

---

## Reglas de negocio

- RN-001: Solo usuarios autenticados pueden contactar vendedores.
- RN-002: Todo mensaje debe asociarse a un libro y a una tienda.
- RN-003: El vendedor solo puede ver mensajes relacionados con su tienda.
- RN-004: El comprador solo puede ver sus propias conversaciones.
- RN-005: Si la mensajeria interna no esta disponible, el sistema puede ofrecer un contacto alternativo visible en la tienda.
