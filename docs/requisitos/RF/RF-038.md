# RF-038 — Disponibilidad de libros

## Identificacion

| Campo | Valor |
|---|---|
| ID | RF-038 |
| Nombre | Validacion de disponibilidad |
| Modulo | Catalogo e inventario |
| Prioridad | Alta |
| Estado | Alcance final |

## Descripcion

El sistema debe mostrar si cada libro esta disponible en formato fisico o digital.

## Proceso

1. El negocio registra la disponibilidad del libro y su formato.
2. El sistema valida y guarda el estado.
3. El catalogo y la ficha del libro muestran la disponibilidad actual.

## Reglas de negocio

- La disponibilidad debe corresponder a una publicacion existente.
- Un libro no disponible no debe presentarse como disponible para compra.
