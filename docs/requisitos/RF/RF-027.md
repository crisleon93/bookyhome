# RF-027 — Compartir publicaciones

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-027 |
| Nombre | Compartir publicaciones |
| Módulo | Difusión |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir compartir publicaciones mediante enlaces o plataformas externas.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| publication_id | UUID | Sí |

---

## Proceso

1. El usuario selecciona compartir.
2. El sistema genera un enlace.
3. Se presenta la opción de difusión.
4. El enlace puede ser distribuido.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Enlace generado | 200 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| GET | /api/v1/books/{id}/share |

---

## Reglas de negocio

- RN-001: El enlace debe ser único.
- RN-002: Debe dirigir a la publicación original.
