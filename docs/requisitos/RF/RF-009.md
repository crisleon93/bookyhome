# RF-009 — Visualización de catálogo

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-009 |
| Nombre | Visualización de catálogo |
| Módulo | Catálogo |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe mostrar un catálogo con todas las publicaciones disponibles para consulta por parte de los usuarios.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| page | Entero | No | Mayor que 0 |
| limit | Entero | No | Mayor que 0 |

---

## Proceso

1. El usuario accede al catálogo.
2. El sistema consulta las publicaciones activas.
3. Se organiza la información.
4. Se aplican criterios de paginación.
5. Se muestran los resultados.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Consulta exitosa | 200 | Catálogo disponible |

---

## Endpoints asociados

| Método | Ruta | Auth requerida | Descripción |
|----------|----------|----------|----------|
| GET | /api/v1/books | No | Consultar catálogo |

---

## Reglas de negocio

- RN-001: Solo publicaciones activas deben mostrarse.
- RN-002: El catálogo debe soportar paginación.
- RN-003: Debe mostrarse información resumida de cada libro.
