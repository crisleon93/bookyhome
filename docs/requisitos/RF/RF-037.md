# RF-037 — Perfil de negocio

## Identificacion

| Campo | Valor |
|---|---|
| ID | RF-037 |
| Nombre | Gestion de perfil de negocio |
| Modulo | Tiendas |
| Prioridad | Media |
| Estado | Alcance final |

## Descripcion

El sistema debe permitir que un negocio actualice la informacion de su tienda, incluyendo nombre, datos de contacto y descripcion.

## Proceso

1. El negocio accede a la configuracion de su tienda.
2. Modifica los datos permitidos.
3. El sistema valida y guarda los cambios.
4. La informacion actualizada queda visible para los usuarios segun la configuracion de la tienda.

## Reglas de negocio

- Solo el negocio propietario o un administrador autorizado puede modificar el perfil.
- Los datos obligatorios deben validarse antes de guardar.
