# RF-006 — Gestión de publicaciones

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-006 |
| Nombre | Gestión de publicaciones |
| Módulo | Gestión de Publicaciones |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir que los negocios administren las publicaciones de libros registradas, posibilitando la actualización o eliminación de información cuando sea necesario.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| publication_id | UUID | Sí | Debe existir |
| title | Texto | No | Mínimo 2 caracteres |
| author | Texto | No | Mínimo 2 caracteres |
| category | Texto | No | Categoría válida |
| description | Texto | No | Máximo 2000 caracteres |
| price | Decimal | No | Mayor que 0 |
| stock | Entero | No | Mayor o igual a 0 |

---

## Proceso

1. El negocio accede al módulo de publicaciones.
2. Consulta sus publicaciones registradas.
3. Selecciona una publicación.
4. Elige editar o eliminar.
5. El sistema valida permisos de acceso.
6. Se procesan los cambios solicitados.
7. La información se actualiza en la base de datos.
8. El catálogo refleja los cambios realizados.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Actualización exitosa | 200 | Publicación actualizada |
| Eliminación exitosa | 200 | Publicación eliminada |
| Publicación inexistente | 404 | No encontrada |
| Sin permisos | 403 | Acceso denegado |

---

## Endpoints asociados

| Método | Ruta | Auth requerida | Descripción |
|----------|----------|----------|----------|
| GET | /api/v1/books/my-books | Sí | Consultar publicaciones |
| PUT | /api/v1/books/{id} | Sí | Actualizar publicación |
| DELETE | /api/v1/books/{id} | Sí | Eliminar publicación |

---

## Reglas de negocio

- RN-001: Solo el propietario puede modificar una publicación.
- RN-002: Solo el propietario puede eliminar una publicación.
- RN-003: Una publicación eliminada deja de mostrarse en el catálogo.
- RN-004: Toda modificación debe validarse antes de almacenarse.
