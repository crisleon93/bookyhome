# RF-024 — Gestión de pedidos

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-024 |
| Nombre | Gestión de pedidos |
| Módulo | Compras |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe administrar los pedidos generados por los usuarios durante el proceso de compra.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| order_id | UUID | Sí |
| status | Texto | Sí |

---

## Proceso

1. El usuario realiza una compra.
2. El sistema genera un pedido.
3. Se registra la información.
4. El pedido actualiza su estado según el proceso.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Pedido creado | 201 |
| Pedido actualizado | 200 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| POST | /api/v1/orders |
| GET | /api/v1/orders/{id} |
| PATCH | /api/v1/orders/{id} |

---

## Reglas de negocio

- RN-001: Todo pedido debe tener un identificador único.
- RN-002: Debe mantenerse el historial de cambios de estado.
