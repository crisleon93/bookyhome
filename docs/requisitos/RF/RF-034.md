# RF-034 — Carrito de compras

---

## Identificacion

| Campo | Valor |
|---------|---------|
| ID | RF-034 |
| Nombre | Carrito de compras |
| Modulo | Compras |
| Prioridad | Alta |
| Estado | Alcance final |
| Fecha | Febrero 2026 |

---

## Descripcion

El sistema debe permitir que compradores autenticados agreguen libros a un carrito de compras, consulten su contenido, modifiquen cantidades, eliminen productos y generen una orden mediante checkout.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| id_libro | Entero | Si |
| cantidad | Entero | Si |
| titulo | Texto | Si |
| autor_libro | Texto | No |
| precio_libro | Decimal | Si |
| imagen | Texto | No |

---

## Proceso

1. El usuario inicia sesion.
2. Selecciona un libro desde catalogo, detalle o recomendacion.
3. Agrega el libro al carrito.
4. El sistema valida disponibilidad y cantidad.
5. El carrito se actualiza.
6. El usuario puede cambiar cantidades o eliminar items.
7. El sistema recalcula el total.
8. El usuario confirma checkout.
9. El sistema genera una orden y vacia el carrito.

---

## Salidas

| Escenario | Codigo HTTP |
|------------|------------|
| Producto agregado | 200/201 |
| Carrito consultado | 200 |
| Item actualizado | 200 |
| Item eliminado | 200 |
| Checkout exitoso | 200 |
| Stock insuficiente | 400 |
| Usuario no autenticado | 401 |

---

## Endpoints objetivo

| Metodo | Ruta | Auth requerida | Descripcion |
|----------|----------|----------|----------|
| GET | /carrito | Si | Consultar carrito del usuario autenticado |
| POST | /carrito | Si | Agregar libro al carrito |
| PATCH | /carrito/{id_libro} | Si | Actualizar cantidad de un item |
| DELETE | /carrito/{id_libro} | Si | Eliminar item del carrito |
| POST | /carrito/clear | Si | Vaciar carrito |
| POST | /carrito/checkout | Si | Crear orden desde carrito |

---

## Reglas de negocio

- RN-001: Solo usuarios autenticados pueden utilizar el carrito.
- RN-002: No se puede superar el stock disponible.
- RN-003: La cantidad minima por item es 1.
- RN-004: El sistema debe recalcular automaticamente el total.
- RN-005: El carrito debe asociarse al usuario del token JWT, no a un id enviado por URL publica.
- RN-006: Al completar checkout, el carrito debe vaciarse y se debe crear una orden.
