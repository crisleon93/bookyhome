# RF-034 — Carrito de compras

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-034 |
| Nombre | Carrito de compras |
| Módulo | Compras |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir que los usuarios agreguen libros a un carrito de compras antes de realizar el proceso de pago.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| user_id | UUID | Sí |
| book_id | UUID | Sí |
| quantity | Entero | Sí |

---

## Proceso

1. El usuario selecciona un libro.
2. Agrega el libro al carrito.
3. El sistema valida disponibilidad.
4. Se actualiza el contenido del carrito.
5. El usuario puede modificar o eliminar elementos.
6. El sistema calcula el valor total.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Producto agregado | 201 |
| Carrito actualizado | 200 |
| Stock insuficiente | 400 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| POST | /api/v1/cart |
| GET | /api/v1/cart |
| PUT | /api/v1/cart/{id} |
| DELETE | /api/v1/cart/{id} |

---

## Reglas de negocio

- RN-001: Solo usuarios autenticados pueden utilizar el carrito.
- RN-002: No se puede superar el stock disponible.
- RN-003: El sistema debe recalcular automáticamente el total.
- RN-004: El carrito debe conservarse durante la sesión activa.
