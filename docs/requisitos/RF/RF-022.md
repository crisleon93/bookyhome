# RF-022 — Bloqueo y desbloqueo de usuarios

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-022 |
| Nombre | Bloqueo y desbloqueo de usuarios |
| Módulo | Administración |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir bloquear o desbloquear usuarios cuando sea necesario por motivos administrativos o de seguridad.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| user_id | UUID | Sí |
| status | Texto | Sí |

---

## Proceso

1. El administrador selecciona un usuario.
2. Escoge bloquear o desbloquear.
3. El sistema valida permisos.
4. Actualiza el estado del usuario.
5. Registra la acción realizada.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Operación exitosa | 200 |
| Usuario inexistente | 404 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| PATCH | /api/v1/users/{id}/status |

---

## Reglas de negocio

- RN-001: Solo administradores pueden ejecutar esta acción.
- RN-002: Los usuarios bloqueados no podrán iniciar sesión.
