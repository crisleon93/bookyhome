# RF-019 — Reporte de publicaciones

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-019 |
| Nombre | Reporte de publicaciones |
| Módulo | Moderación |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir reportar publicaciones que incumplan las políticas de la plataforma.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| publication_id | UUID | Sí |
| reason | Texto | Sí |

---

## Proceso

1. El usuario selecciona reportar.
2. Indica el motivo.
3. El sistema registra el reporte.
4. El administrador puede revisarlo.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Reporte registrado | 201 |
| Error validación | 422 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| POST | /api/v1/reports |

---

## Reglas de negocio

- RN-001: Todo reporte debe tener un motivo.
- RN-002: Los reportes deben conservarse para auditoría.
