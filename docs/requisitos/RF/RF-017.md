# RF-017 — Historial de actividad

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-017 |
| Nombre | Historial de actividad |
| Módulo | Usuarios |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe registrar las actividades realizadas por los usuarios dentro de la plataforma.

---

## Entradas

N/A (generadas automáticamente por el sistema).

---

## Proceso

1. El usuario realiza una acción.
2. El sistema registra el evento.
3. Se almacena fecha, tipo y referencia.
4. El historial queda disponible para consulta.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Consulta exitosa | 200 | Historial disponible |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| GET | /api/v1/activity-log |

---

## Reglas de negocio

- RN-001: Toda actividad relevante debe registrarse.
- RN-002: El historial pertenece únicamente al usuario.
