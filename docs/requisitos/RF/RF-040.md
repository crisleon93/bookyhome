# RF-040 — Promociones y descuentos

## Identificacion

| Campo | Valor |
|---|---|
| ID | RF-040 |
| Nombre | Promociones y descuentos |
| Modulo | Ventas |
| Prioridad | Media |
| Estado | Alcance final |

## Descripcion

El sistema debe permitir al negocio crear promociones o descuentos y mostrarlos en el catalogo junto con las publicaciones aplicables.

## Proceso

1. El negocio selecciona una o mas publicaciones.
2. Define el descuento y su vigencia.
3. El sistema valida y registra la promocion.
4. El catalogo muestra el precio y la promocion vigente.

## Reglas de negocio

- La promocion debe tener una vigencia valida.
- El descuento no puede producir un precio negativo.
- Las promociones vencidas dejan de mostrarse como activas.
