# RF-025 — Gestion de pagos

---

## Identificacion

| Campo | Valor |
|---------|---------|
| ID | RF-025 |
| Nombre | Gestion de pagos |
| Modulo | Pagos |
| Prioridad | Alta |
| Estado | Alcance final |
| Fecha | Febrero 2026 |

---

## Descripcion

El sistema debe permitir registrar y procesar pagos asociados a ordenes generadas desde el carrito. El flujo final debe validar el valor pagado, asociar el pago a una orden y actualizar el estado correspondiente.

En una primera version, el pago puede ser simulado o registrado internamente. En una version posterior, puede integrarse una pasarela real.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| id_orden | Entero | Si |
| amount | Decimal | Si |
| payment_method | Texto | Si |
| card_data/token | Objeto/Texto | No |

---

## Proceso

1. El comprador confirma el checkout del carrito.
2. El sistema crea una orden pendiente.
3. El comprador ingresa o selecciona metodo de pago.
4. El sistema valida que el monto coincida con el total de la orden.
5. Se registra el pago.
6. La orden cambia de estado segun el resultado.
7. El usuario visualiza confirmacion del pago.

---

## Salidas

| Escenario | Codigo HTTP |
|------------|------------|
| Pago registrado | 200 |
| Orden no encontrada | 404 |
| Valor no coincide | 400 |
| Pago rechazado | 400 |

---

## Endpoints objetivo

| Metodo | Ruta | Auth requerida | Descripcion |
|----------|----------|----------|----------|
| POST | /api/v1/payments | Si | Registrar/procesar pago |
| GET | /api/v1/orders | Si | Consultar ordenes del usuario |
| GET | /api/v1/orders/{id_orden} | Si | Consultar detalle de orden |
| POST | /api/v1/orders/{id_orden}/send-confirmation | Si | Enviar confirmacion, si aplica |

---

## Reglas de negocio

- RN-001: Todo pago debe asociarse a una orden existente.
- RN-002: El valor pagado debe coincidir con el total de la orden.
- RN-003: Un pago exitoso debe actualizar el estado de la orden.
- RN-004: El usuario solo puede pagar ordenes propias.
- RN-005: El sistema debe conservar registro del pago.
