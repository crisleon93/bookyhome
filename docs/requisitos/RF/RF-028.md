# RF-028 — Estadísticas de ventas

---

| Campo | Valor |
|---------|---------|
| ID | RF-028 |
| Nombre | Estadísticas de ventas |
| Módulo | Analítica |
| Prioridad | Media |
| Estado | Implementado |

---

## Descripción

El sistema debe proporcionar estadísticas relacionadas con ventas e interacciones de publicaciones.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| business_id | UUID | Sí |

---

## Proceso

1. El negocio accede al módulo de estadísticas.
2. El sistema recopila información.
3. Calcula indicadores.
4. Presenta los resultados.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Consulta exitosa | 200 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| GET | /api/v1/statistics |

---

## Reglas de negocio

- RN-001: Solo el propietario puede consultar sus estadísticas.
- RN-002: Los datos deben mantenerse actualizados.
