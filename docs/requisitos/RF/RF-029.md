# RF-029 — Acceso multidispositivo

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-029 |
| Nombre | Acceso multidispositivo |
| Módulo | Autenticación |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir acceder a la cuenta desde distintos dispositivos compatibles.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| email | Texto | Sí |
| password | Texto | Sí |

---

## Proceso

1. El usuario inicia sesión desde un dispositivo.
2. El sistema valida credenciales.
3. Se autoriza el acceso.
4. Se sincroniza la información necesaria.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Acceso exitoso | 200 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| POST | /api/v1/auth/login |

---

## Reglas de negocio

- RN-001: La información debe mantenerse consistente.
- RN-002: Los controles de seguridad deben aplicarse en todos los dispositivos.
