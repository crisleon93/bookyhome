# RF-008 — Filtrado por categorías

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-008 |
| Nombre | Filtrado por categorías |
| Módulo | Catálogo |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir filtrar publicaciones de libros según la categoría seleccionada por el usuario.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| category | Texto | Sí | Categoría válida |

---

## Proceso

1. El usuario accede al catálogo.
2. Selecciona una categoría.
3. El sistema consulta las publicaciones asociadas.
4. Se aplican los filtros correspondientes.
5. Se muestran los resultados encontrados.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Resultados encontrados | 200 | Publicaciones filtradas |
| Categoría inválida | 422 | Error de validación |

---

## Endpoints asociados

| Método | Ruta | Auth requerida | Descripción |
|----------|----------|----------|----------|
| GET | /api/v1/books?category={category} | No | Filtrar por categoría |

---

## Reglas de negocio

- RN-001: Solo categorías activas pueden utilizarse.
- RN-002: Las publicaciones deben pertenecer a la categoría seleccionada.
- RN-003: El filtro puede combinarse con búsquedas.
