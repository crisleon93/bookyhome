# RF-012 — Notificaciones de mensajes

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-012 |
| Nombre | Notificaciones de mensajes |
| Módulo | Notificaciones |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe generar notificaciones cuando existan nuevos mensajes asociados a una conversación.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| message_id | UUID | Sí | Debe existir |
| user_id | UUID | Sí | Usuario válido |

---

## Proceso

1. Se registra un nuevo mensaje.
2. El sistema identifica al destinatario.
3. Se genera una notificación.
4. La notificación se almacena.
5. El usuario puede consultarla desde la plataforma.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Notificación generada | 201 | Registro exitoso |
| Error de procesamiento | 500 | Error interno |

---

## Endpoints asociados

| Método | Ruta | Auth requerida | Descripción |
|----------|----------|----------|----------|
| GET | /api/v1/notifications | Sí | Consultar notificaciones |
| PATCH | /api/v1/notifications/{id}/read | Sí | Marcar como leída |

---

## Reglas de negocio

- RN-001: Toda notificación debe asociarse a un mensaje.
- RN-002: Las notificaciones deben almacenarse en el historial.
- RN-003: Las notificaciones pueden marcarse como leídas.
- RN-004: Solo el destinatario puede visualizar sus notificaciones.
