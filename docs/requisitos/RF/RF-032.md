# RF-032 — Gestión de opciones de envío

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-032 |
| Nombre | Gestión de opciones de envío |
| Módulo | Logística |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir a los negocios configurar opciones de envío para los libros publicados dentro de la plataforma.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| publication_id | UUID | Sí |
| shipping_type | Texto | Sí |
| shipping_cost | Decimal | Sí |
| estimated_time | Texto | Sí |

---

## Proceso

1. El negocio accede a la publicación.
2. Configura las opciones de envío.
3. El sistema valida los datos ingresados.
4. La información es almacenada.
5. Las opciones quedan disponibles para los compradores.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Configuración registrada | 201 |
| Configuración actualizada | 200 |
| Error de validación | 422 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| POST | /api/v1/shipping-options |
| PUT | /api/v1/shipping-options/{id} |
| GET | /api/v1/shipping-options/{id} |

---

## Reglas de negocio

- RN-001: Solo el propietario de la publicación puede configurar envíos.
- RN-002: El costo de envío debe ser mayor o igual a cero.
- RN-003: Toda opción debe estar asociada a una publicación activa.
