# RF-007 — Búsqueda de libros

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-007 |
| Nombre | Búsqueda de libros |
| Módulo | Catálogo |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir a los usuarios buscar libros mediante criterios como título, autor o palabras clave asociadas a las publicaciones.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| query | Texto | Sí | Mínimo 1 carácter |
| page | Entero | No | Mayor que 0 |
| limit | Entero | No | Mayor que 0 |

---

## Proceso

1. El usuario accede al buscador.
2. Ingresa un criterio de búsqueda.
3. El sistema procesa la consulta.
4. Se buscan coincidencias en las publicaciones activas.
5. Los resultados se ordenan según relevancia.
6. El sistema devuelve la lista encontrada.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Resultados encontrados | 200 | Lista de publicaciones |
| Sin resultados | 200 | Lista vacía |
| Parámetros inválidos | 422 | Error de validación |

---

## Endpoints asociados

| Método | Ruta | Auth requerida | Descripción |
|----------|----------|----------|----------|
| GET | /api/v1/books/search | No | Buscar libros |

---

## Reglas de negocio

- RN-001: La búsqueda debe ignorar mayúsculas y minúsculas.
- RN-002: Deben permitirse coincidencias parciales.
- RN-003: Solo se mostrarán publicaciones activas.
- RN-004: Los resultados deben paginarse.
