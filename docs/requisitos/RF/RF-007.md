# RF-007 — Busqueda de libros

---

## Identificacion

| Campo | Valor |
|---------|---------|
| ID | RF-007 |
| Nombre | Busqueda de libros |
| Modulo | Catalogo |
| Prioridad | Alta |
| Estado | Alcance final |
| Fecha | Febrero 2026 |

---

## Descripcion

El sistema debe permitir que los usuarios busquen libros disponibles en BookyHome mediante titulo, autor, categoria, tienda o palabras clave relacionadas con la publicacion.

La busqueda debe estar disponible desde el catalogo y desde el buscador global del header.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| q | Texto | No | Minimo 1 caracter cuando se envie |
| categoria | Texto/ID | No | Debe corresponder a una categoria existente |
| autor | Texto | No | Coincidencia parcial |
| tienda | Texto/ID | No | Coincidencia parcial o tienda existente |
| precio_min | Decimal | No | Mayor o igual a 0 |
| precio_max | Decimal | No | Mayor o igual a `precio_min` |
| disponibilidad | Texto | No | Disponible, sin stock o todos |
| orden | Texto | No | Relevancia, precio menor, precio mayor, recientes |

---

## Proceso

1. El usuario ingresa un criterio de busqueda desde el header o catalogo.
2. El sistema envia el criterio al catalogo.
3. El catalogo consulta los libros disponibles.
4. Se aplican busqueda, filtros y ordenamiento.
5. El sistema muestra los resultados encontrados.
6. Si no hay coincidencias, se informa al usuario y se ofrecen acciones para limpiar filtros o volver al catalogo.

---

## Salidas

| Escenario | Codigo HTTP | Respuesta |
|------------|------------|------------|
| Resultados encontrados | 200 | Lista de libros |
| Sin resultados | 200 | Lista vacia con mensaje claro |
| Parametros invalidos | 422 | Error de validacion |

---

## Endpoints objetivo

| Metodo | Ruta | Auth requerida | Descripcion |
|----------|----------|----------|----------|
| GET | /api/stored/libros | No | Listar libros del catalogo |
| GET | /api/stored/libros/{id_libro} | No | Consultar detalle de libro |
| GET | /libros/categorias | No | Consultar categorias disponibles |

> Nota: La busqueda puede implementarse inicialmente en frontend sobre la lista de libros y evolucionar a busqueda backend si el volumen de datos lo requiere.

---

## Reglas de negocio

- RN-001: La busqueda debe ignorar mayusculas y minusculas.
- RN-002: Deben permitirse coincidencias parciales.
- RN-003: Solo se deben mostrar libros visibles y disponibles para catalogo.
- RN-004: Los filtros deben poder combinarse.
- RN-005: El buscador global debe llevar al usuario al catalogo con los resultados filtrados.
