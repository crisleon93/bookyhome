# RF-014 — Comentarios sobre libros

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-014 |
| Nombre | Comentarios sobre libros |
| Módulo | Valoraciones |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir que los usuarios publiquen comentarios relacionados con libros disponibles en la plataforma.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| book_id | UUID | Sí | Debe existir |
| comment | Texto | Sí | Máximo 1000 caracteres |

---

## Proceso

1. El usuario accede a una publicación.
2. Ingresa un comentario.
3. El sistema valida el contenido.
4. El comentario es almacenado.
5. Se asocia a la publicación.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Comentario registrado | 201 | Comentario creado |
| Datos inválidos | 422 | Error de validación |

---

## Endpoints asociados

| Método | Ruta | Auth requerida | Descripción |
|----------|----------|----------|----------|
| POST | /api/v1/comments | Sí | Crear comentario |
| GET | /api/v1/comments/book/{id} | No | Consultar comentarios |

---

## Reglas de negocio

- RN-001: Solo usuarios autenticados pueden comentar.
- RN-002: El comentario debe asociarse a un libro existente.
- RN-003: El sistema debe almacenar fecha y autor.
