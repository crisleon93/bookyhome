# RF-033 — Comparación de libros

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-033 |
| Nombre | Comparación de libros |
| Módulo | Catálogo |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir comparar múltiples libros para facilitar la toma de decisiones por parte del usuario.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| book_ids | Lista UUID | Sí |

---

## Proceso

1. El usuario selecciona libros para comparar.
2. El sistema recupera la información correspondiente.
3. Se organizan los datos comparables.
4. Se muestran los resultados en una vista unificada.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Comparación generada | 200 |
| Libros no encontrados | 404 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| POST | /api/v1/books/compare |

---

## Reglas de negocio

- RN-001: Solo se pueden comparar libros existentes.
- RN-002: La comparación debe mostrar información homogénea.
- RN-003: Deben visualizarse características relevantes de cada libro.
