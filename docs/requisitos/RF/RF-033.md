# RF-033 — Comparacion de libros

---

## Identificacion

| Campo | Valor |
|---------|---------|
| ID | RF-033 |
| Nombre | Comparacion de libros |
| Modulo | Catalogo |
| Prioridad | Baja |
| Estado | Alcance final |
| Fecha | Febrero 2026 |

---

## Descripcion

El sistema debe permitir comparar dos o mas libros para facilitar la decision de compra. La comparacion debe mostrar datos relevantes como precio, autor, categoria, estado, disponibilidad, tienda y valoraciones si existen.

Esta funcionalidad pertenece al alcance final, pero no es prioritaria frente a catalogo, carrito, checkout y gestion de vendedor.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| ids_libros | Lista de enteros | Si |

---

## Proceso

1. El usuario selecciona libros desde el catalogo o favoritos.
2. El sistema agrega los libros a una lista de comparacion.
3. El usuario abre la vista comparativa.
4. El sistema organiza los atributos comparables.
5. El usuario puede quitar libros de la comparacion.

---

## Salidas

| Escenario | Codigo HTTP |
|------------|------------|
| Comparacion generada | 200 |
| Libro no encontrado | 404 |
| Cantidad insuficiente de libros | 400 |

---

## Endpoints objetivo

| Metodo | Ruta | Auth requerida | Descripcion |
|----------|----------|----------|----------|
| GET | /api/stored/libros | No | Obtener libros para comparar |
| GET | /api/stored/libros/{id_libro} | No | Obtener detalle de cada libro |

> Nota: La primera version puede implementarse en frontend usando datos del catalogo. Un endpoint dedicado de comparacion puede agregarse si el volumen o complejidad lo requiere.

---

## Reglas de negocio

- RN-001: Solo se pueden comparar libros existentes.
- RN-002: La comparacion debe mostrar informacion homogenea.
- RN-003: Deben compararse minimo dos libros.
- RN-004: Se debe permitir retirar libros de la comparacion.
