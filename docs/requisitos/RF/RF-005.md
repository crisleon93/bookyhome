# RF-005 — Publicación de libros

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-005 |
| Nombre | Publicación de libros |
| Módulo | Gestión de Publicaciones |
| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir que los negocios registrados publiquen libros dentro de la plataforma, proporcionando la información necesaria para que los usuarios puedan consultar y acceder a las publicaciones disponibles en el catálogo.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| title | Texto | Sí | Mínimo 2 caracteres, máximo 255 |
| author | Texto | Sí | Mínimo 2 caracteres |
| category | Texto | Sí | Debe existir en el catálogo de categorías |
| description | Texto | Sí | Máximo 2000 caracteres |
| price | Decimal | Sí | Mayor que 0 |
| stock | Entero | Sí | Mayor o igual a 0 |
| image_url | URL | No | Formato válido |
| condition | Texto | Sí | Nuevo o usado |

---

## Proceso

1. El negocio accede al módulo de publicaciones.
2. Selecciona la opción **"Publicar libro"**.
3. Ingresa la información requerida del libro.
4. El frontend valida los campos obligatorios.
5. La información es enviada al backend.
6. El sistema valida formatos, restricciones y reglas de negocio.
7. Se verifica que el usuario posea permisos de negocio.
8. Se registra la publicación en la base de datos.
9. El sistema asigna estado activo a la publicación.
10. Se almacena la información asociada al libro.
11. La publicación queda disponible para consulta en el catálogo.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Publicación creada | 201 | Datos completos de la publicación |
| Datos inválidos | 422 | Error de validación |
| Usuario no autorizado | 401 | Error de autenticación |
| Permisos insuficientes | 403 | Acceso denegado |

---

## Endpoints asociados

| Método | Ruta | Auth requerida | Descripción |
|----------|----------|----------|----------|
| POST | /api/v1/books | Sí | Crear publicación |
| GET | /api/v1/books/{id} | No | Consultar publicación |
| PUT | /api/v1/books/{id} | Sí | Actualizar publicación |
| DELETE | /api/v1/books/{id} | Sí | Eliminar publicación |

---

## Reglas de negocio

- RN-001: Solo negocios autenticados pueden publicar libros.
- RN-002: Toda publicación debe estar asociada a un negocio registrado.
- RN-003: El precio del libro debe ser mayor que cero.
- RN-004: El stock no puede ser negativo.
- RN-005: Toda publicación debe pertenecer a una categoría válida.
- RN-006: Las publicaciones activas serán visibles en el catálogo.
- RN-007: La información registrada debe cumplir las validaciones definidas por el sistema.
- RN-008: Una publicación eliminada dejará de mostrarse a los usuarios.
