# RF-039 — Gestion de stock

## Identificacion

| Campo | Valor |
|---|---|
| ID | RF-039 |
| Nombre | Gestion de stock |
| Modulo | Inventario |
| Prioridad | Alta |
| Estado | Alcance final |

## Descripcion

El sistema debe permitir al negocio indicar y actualizar la cantidad disponible de cada libro.

## Proceso

1. El negocio registra la cantidad inicial disponible.
2. El sistema actualiza la cantidad cuando se confirma una venta.
3. El negocio puede corregir la cantidad disponible.
4. El sistema refleja cuando el stock llega a cero.

## Reglas de negocio

- La cantidad disponible no puede ser negativa.
- Las actualizaciones de stock deben asociarse a la publicacion correspondiente.
