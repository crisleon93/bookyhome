# RF-041 — Historial de interacciones del usuario

## Identificacion

| Campo | Valor |
|---|---|
| ID | RF-041 |
| Nombre | Historial de interaccion |
| Modulo | Experiencia de usuario |
| Prioridad | Media |
| Estado | Alcance final |

## Descripcion

El sistema debe mostrar al usuario su historial de libros visualizados y mensajes enviados. Este historial visible para el usuario es distinto del registro tecnico de actividad definido en RF-017.

## Proceso

1. El sistema registra las visualizaciones de publicaciones y los mensajes enviados por el usuario.
2. El usuario accede a su historial.
3. El sistema muestra las interacciones asociadas a su cuenta.

## Reglas de negocio

- Cada usuario solo puede consultar su propio historial.
- Las interacciones deben asociarse a la publicacion o conversacion correspondiente.
