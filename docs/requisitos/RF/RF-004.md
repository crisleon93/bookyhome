# RF-004 — Cierre de sesión

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-004 |
| Nombre | Cierre de sesión |
| Módulo | Autenticación |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

## Descripción

El sistema debe permitir que el usuario cierre sesión manualmente desde cualquier dispositivo.

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| access_token | JWT | Sí | Token válido |

## Proceso

1. El usuario selecciona cerrar sesión.
2. El frontend envía la solicitud.
3. El backend valida el token.
4. Se invalida la sesión activa.
5. Se eliminan credenciales temporales.
6. El usuario es redirigido al acceso principal.

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Cierre exitoso | 200 | Sesión cerrada |
| Token inválido | 401 | No autorizado |

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| POST | /api/v1/auth/logout |

## Reglas de negocio

- RN-001: Toda sesión puede cerrarse manualmente.
- RN-002: Los tokens invalidados no pueden reutilizarse.
