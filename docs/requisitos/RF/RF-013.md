# RF-013 — Calificación de libros

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-013 |
| Nombre | Calificación de libros |
| Módulo | Valoraciones |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir que los usuarios califiquen los libros utilizando una escala de valoración para compartir su percepción sobre una publicación.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| book_id | UUID | Sí | Debe existir |
| rating | Entero | Sí | Valor entre 1 y 5 |

---

## Proceso

1. El usuario accede a la publicación.
2. Selecciona una calificación.
3. El sistema valida la información.
4. Se registra la valoración.
5. Se actualiza el promedio de calificaciones.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Calificación registrada | 201 | Valoración almacenada |
| Valor inválido | 422 | Error de validación |

---

## Endpoints asociados

| Método | Ruta | Auth requerida | Descripción |
|----------|----------|----------|----------|
| POST | /api/v1/ratings | Sí | Registrar calificación |

---

## Reglas de negocio

- RN-001: La valoración debe estar entre 1 y 5.
- RN-002: Un usuario puede actualizar su calificación.
- RN-003: Las calificaciones afectan el promedio del libro.
