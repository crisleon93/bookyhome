# RF-031 — Reseñas verificadas

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-031 |
| Nombre | Reseñas verificadas |
| Módulo | Valoraciones |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe marcar como compra verificada una reseña asociada a una compra completada dentro de la plataforma. La creacion de calificaciones y comentarios se especifica en RF-013 y RF-014.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| user_id | UUID | Sí |
| book_id | UUID | Sí |
| review_id | UUID | Sí |

---

## Proceso

1. El sistema identifica la reseña y el libro relacionado.
2. Verifica si el usuario tiene una compra completada de ese libro.
3. Marca la reseña como verificada solo si la compra existe.
4. Muestra el distintivo junto a la reseña.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Compra verificada | 200 | Distintivo habilitado |
| Compra no acreditada | 200 | Sin distintivo de verificacion |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| GET | /api/v1/reviews/book/{id} |

---

## Reglas de negocio

- RN-001: Una reseña se marca como verificada únicamente si existe una compra completada asociada al usuario y al libro.
- RN-002: El sistema no debe mostrar el distintivo si no puede validar la compra.
