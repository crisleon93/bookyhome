# RF-031 — Reseñas verificadas

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-031 |
| Nombre | Reseñas verificadas |
| Módulo | Valoraciones |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir identificar y mostrar reseñas verificadas realizadas por usuarios que hayan adquirido previamente el libro dentro de la plataforma.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| user_id | UUID | Sí |
| book_id | UUID | Sí |
| comment | Texto | Sí |
| rating | Entero | Sí |

---

## Proceso

1. El usuario registra una reseña.
2. El sistema verifica si existe una compra asociada.
3. Se valida la información ingresada.
4. La reseña se almacena en la base de datos.
5. Se marca como verificada cuando corresponde.
6. La reseña queda disponible para consulta.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Reseña registrada | 201 |
| Compra no encontrada | 403 |
| Error de validación | 422 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| POST | /api/v1/reviews |
| GET | /api/v1/reviews/book/{id} |

---

## Reglas de negocio

- RN-001: Solo usuarios autenticados pueden publicar reseñas.
- RN-002: Una reseña será verificada únicamente si existe una compra asociada.
- RN-003: Las reseñas verificadas deben diferenciarse visualmente.
- RN-004: Un usuario puede actualizar su propia reseña.
