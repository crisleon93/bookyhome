# RF-018 — Gestión de categorías

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-018 |
| Nombre | Gestión de categorías |
| Módulo | Administración |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir administrar las categorías utilizadas por las publicaciones.

---

## Entradas

| Campo | Tipo | Obligatorio |
|---------|---------|---------|
| name | Texto | Sí |
| description | Texto | No |

---

## Proceso

1. El administrador crea o modifica categorías.
2. El sistema valida la información.
3. Se actualizan los registros correspondientes.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Operación exitosa | 200 |
| Error validación | 422 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| POST | /api/v1/categories |
| PUT | /api/v1/categories/{id} |
| DELETE | /api/v1/categories/{id} |

---

## Reglas de negocio

- RN-001: Las categorías deben ser únicas.
- RN-002: Solo administradores pueden gestionarlas.
