# RF-036 — Reporte y Moderación de Contenido

---

| Campo | Valor |
|---------|---------|

| Prioridad | Alta |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir a los usuarios reportar publicaciones de libros que contengan información falsa, inapropiada o que incumpla las políticas de la plataforma. Los reportes serán gestionados por los administradores para determinar las acciones correspondientes sobre el contenido reportado.

---

## Entradas

| Campo | Tipo | Obligatorio | Validaciones |
|---------|---------|---------|---------|
| publication_id | UUID | Sí | Debe existir |
| reason | Texto | Sí | Máximo 500 caracteres |
| report_type | Texto | Sí | Debe corresponder a una categoría válida |
| additional_comments | Texto | No | Máximo 1000 caracteres |

---

## Proceso

1. El usuario accede a una publicación disponible en la plataforma.
2. Selecciona la opción "Reportar publicación".
3. Indica el motivo del reporte.
4. El sistema valida la información ingresada.
5. Se registra el reporte en la base de datos.
6. El sistema notifica a los administradores sobre el nuevo reporte.
7. El administrador revisa el contenido reportado.
8. Se analiza el cumplimiento de las políticas de la plataforma.
9. El administrador determina la acción correspondiente.
10. El sistema actualiza el estado del reporte.
11. La publicación puede mantenerse activa, ser suspendida o eliminada según el resultado de la revisión.

---

## Salidas

| Escenario | Código HTTP | Respuesta |
|------------|------------|------------|
| Reporte registrado correctamente | 201 | Reporte creado |
| Publicación no encontrada | 404 | Recurso no encontrado |
| Datos inválidos | 422 | Error de validación |
| Moderación completada | 200 | Estado actualizado |

---

## Reglas de negocio

- RN-001: Solo usuarios autenticados pueden generar reportes.
- RN-002: Todo reporte debe estar asociado a una publicación existente.
- RN-003: El motivo del reporte es obligatorio.
- RN-004: Los administradores son los únicos autorizados para moderar contenido reportado.
- RN-005: Toda acción de moderación debe quedar registrada para auditoría.
- RN-006: Una publicación suspendida no debe mostrarse en el catálogo.
- RN-007: El sistema debe conservar el historial de reportes asociados a cada publicación.
- RN-008: Un reporte debe mantener un estado de seguimiento (Pendiente, En revisión, Resuelto o Rechazado).
