# RF-023 — Historial de compras

---

## Identificación

| Campo | Valor |
|---------|---------|
| ID | RF-023 |
| Nombre | Historial de compras |
| Módulo | Compras |
| Prioridad | Media |
| Estado | Implementado |
| Fecha | Febrero 2026 |

---

## Descripción

El sistema debe permitir consultar el historial de compras realizadas por un usuario.

---

## Entradas

N/A

---

## Proceso

1. El usuario accede al historial.
2. El sistema consulta las compras asociadas.
3. Organiza la información cronológicamente.
4. Presenta los resultados.

---

## Salidas

| Escenario | Código HTTP |
|------------|------------|
| Consulta exitosa | 200 |

---

## Endpoints asociados

| Método | Ruta |
|----------|----------|
| GET | /api/v1/orders/history |

---

## Reglas de negocio

- RN-001: Cada usuario solo puede consultar su historial.
- RN-002: El historial debe conservar los registros realizados.
