# HU-042 Consultar y gestionar pedidos

## Identificacion

| Campo | Valor |
|---|---|
| ID | HU-042 |
| Titulo | Consultar y gestionar pedidos |
| Modulo | Compras |
| Prioridad | Alta |
| Estado | Definida |
| RF asociados | RF24 |

## Historia

Como usuario, requiero consultar mis pedidos y su estado para dar seguimiento a las compras realizadas.

## Criterios de aceptacion

### CA-042.1 — Consulta de pedido

**Dado que** el usuario tiene un pedido registrado,

**Cuando** consulta el detalle del pedido,

**Entonces** el sistema debe mostrar los libros y el estado actual.

### CA-042.2 — Actualizacion del estado

**Dado que** ocurre un cambio valido en el proceso del pedido,

**Cuando** el sistema actualiza el estado,

**Entonces** debe conservar la informacion actualizada del pedido.
