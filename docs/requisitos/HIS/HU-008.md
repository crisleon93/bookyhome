# HU-008 Reportar publicaciones inapropiadas

---

## Identificación

| Campo        | Valor                               |
| ------------ | ----------------------------------- |
| ID           | HU-008                              |
| Título       | Reportar publicaciones inapropiadas |
| Módulo       | Moderación de Contenido             |
| Prioridad    | Alta                                |
| Estado       | Definida                            |
| RF asociados | RF24, RF36                          |

---

## Historia

Como usuario, requiero reportar publicaciones que contengan información inapropiada, falsa o que incumpla las políticas de la plataforma para contribuir al mantenimiento de la calidad y confiabilidad del contenido disponible.

---

## Criterios de aceptación

### CA-008.1 — Acceso a la funcionalidad de reporte

**Dado que** el usuario se encuentra visualizando una publicación,

**Cuando** selecciona la opción de reportar contenido,

**Entonces** el sistema deberá mostrar el formulario de reporte correspondiente.

---

### CA-008.2 — Selección del motivo del reporte

**Dado que** el usuario desea reportar una publicación,

**Cuando** accede al formulario de reporte,

**Entonces** el sistema deberá permitir la selección de un motivo predefinido.

---

### CA-008.3 — Envío de reporte

**Dado que** el usuario ha diligenciado la información requerida,

**Cuando** confirma el envío del reporte,

**Entonces** el sistema deberá registrar la solicitud y asociarla a la publicación correspondiente.

---

### CA-008.4 — Notificación al administrador

**Dado que** un reporte ha sido registrado correctamente,

**Cuando** el sistema procesa la solicitud,

**Entonces** deberá poner el reporte a disposición del panel de administración para su revisión.

---

### CA-008.5 — Registro de evidencia

**Dado que** se genera un reporte sobre una publicación,

**Cuando** el sistema almacena la información,

**Entonces** deberá conservar el motivo, la fecha, el usuario que realiza el reporte y la publicación asociada.

---

### CA-008.6 — Confirmación de operación

**Dado que** el reporte fue registrado exitosamente,

**Cuando** finaliza el proceso de envío,

**Entonces** el sistema deberá informar al usuario que la solicitud fue recibida correctamente.

---

### CA-008.7 — Restricción de reportes inválidos

**Dado que** el usuario intenta enviar un reporte sin información obligatoria,

**Cuando** confirma la operación,

**Entonces** el sistema deberá impedir el envío e indicar las inconsistencias detectadas.

---

### CA-008.8 — Disponibilidad para revisión administrativa

**Dado que** existen reportes registrados en el sistema,

**Cuando** un administrador accede al módulo de moderación,

**Entonces** deberá visualizar los reportes pendientes junto con la información necesaria para su análisis.
