# HU-007 Guardar libros en favoritos

---

## Identificación

| Campo        | Valor                       |
| ------------ | --------------------------- |
| ID           | HU-007                      |
| Título       | Guardar libros en favoritos |
| Módulo       | Gestión de Favoritos        |
| Prioridad    | Media                       |
| Estado       | Definida                    |
| RF asociados | RF18                        |

---

## Historia

Como usuario, requiero almacenar libros en una lista de favoritos para facilitar su consulta y acceso posterior dentro de la plataforma.

---

## Criterios de aceptación

### CA-007.1 — Agregar libro a favoritos

**Dado que** el usuario se encuentra visualizando una publicación,

**Cuando** selecciona la opción para agregar el libro a favoritos,

**Entonces** el sistema deberá registrar la publicación en la lista personal del usuario.

---

### CA-007.2 — Visualización de favoritos

**Dado que** el usuario posee libros registrados como favoritos,

**Cuando** accede a la sección correspondiente de su perfil,

**Entonces** el sistema deberá mostrar todas las publicaciones almacenadas.

---

### CA-007.3 — Eliminación de favoritos

**Dado que** existe una publicación registrada en la lista de favoritos,

**Cuando** el usuario selecciona la opción para eliminarla,

**Entonces** el sistema deberá retirar la publicación de la lista.

---

### CA-007.4 — Persistencia de información

**Dado que** el usuario agrega un libro a favoritos,

**Cuando** la operación finaliza correctamente,

**Entonces** el sistema deberá conservar la información asociada a futuras sesiones.

---

### CA-007.5 — Prevención de duplicados

**Dado que** una publicación ya se encuentra registrada como favorita,

**Cuando** el usuario intenta agregarla nuevamente,

**Entonces** el sistema deberá evitar la duplicidad del registro.

---

### CA-007.6 — Actualización de la lista

**Dado que** el usuario agrega o elimina una publicación,

**Cuando** el sistema procesa la operación,

**Entonces** la lista de favoritos deberá actualizarse inmediatamente.

---

### CA-007.7 — Confirmación de operación

**Dado que** una acción sobre favoritos se ejecuta correctamente,

**Cuando** finaliza el procesamiento de la solicitud,

**Entonces** el sistema deberá notificar el resultado de la operación al usuario.
