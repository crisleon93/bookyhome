# HU-009 Recibir recomendaciones personalizadas

---

## Identificación

| Campo        | Valor                                  |
| ------------ | -------------------------------------- |
| ID           | HU-009                                 |
| Título       | Recibir recomendaciones personalizadas |
| Módulo       | Recomendaciones                        |
| Prioridad    | Media                                  |
| Estado       | Definida                               |
| RF asociados | RF27                                   |

---

## Historia

Como usuario, requiero recibir recomendaciones de libros basadas en mis búsquedas, interacciones y favoritos para descubrir publicaciones relevantes dentro de la plataforma.

---

## Criterios de aceptación

### CA-009.1 — Análisis de comportamiento

**Dado que** el usuario ha interactuado con la plataforma,

**Cuando** el sistema procese la información disponible,

**Entonces** deberá analizar búsquedas, favoritos e historial para generar recomendaciones.

---

### CA-009.2 — Generación de recomendaciones

**Dado que** existe información suficiente sobre las preferencias del usuario,

**Cuando** el sistema ejecuta el proceso de recomendación,

**Entonces** deberá generar una lista de libros relacionados con los intereses identificados.

---

### CA-009.3 — Visualización de sugerencias

**Dado que** existen recomendaciones disponibles,

**Cuando** el usuario accede a la página principal o a las secciones definidas para recomendaciones,

**Entonces** el sistema deberá mostrar las publicaciones sugeridas.

---

### CA-009.4 — Actualización de recomendaciones

**Dado que** el usuario realiza nuevas búsquedas o agrega libros a favoritos,

**Cuando** el sistema actualiza la información de comportamiento,

**Entonces** deberá recalcular las recomendaciones disponibles.

---

### CA-009.5 — Recomendaciones sin historial suficiente

**Dado que** el usuario no posee historial de actividad relevante,

**Cuando** el sistema intenta generar recomendaciones,

**Entonces** deberá mostrar sugerencias generales basadas en publicaciones destacadas o populares.

---

### CA-009.6 — Evaluación de utilidad

**Dado que** el usuario visualiza una recomendación,

**Cuando** indica si esta resulta útil o no,

**Entonces** el sistema deberá registrar dicha evaluación para futuras recomendaciones.

---

### CA-009.7 — Consistencia de resultados

**Dado que** existen preferencias identificadas para el usuario,

**Cuando** se generan recomendaciones,

**Entonces** las publicaciones sugeridas deberán mantener relación con las categorías o temáticas previamente consultadas.

---

### CA-009.8 — Disponibilidad continua

**Dado que** el usuario accede a la plataforma desde una sesión válida,

**Cuando** consulta las recomendaciones personalizadas,

**Entonces** el sistema deberá presentar la información actualizada según el comportamiento registrado.
