# HU-025 Gestionar usuarios desde el panel administrativo

---

## Identificación

| Campo        | Valor                                            |
| ------------ | ------------------------------------------------ |
| ID           | HU-025                                           |
| Título       | Gestionar usuarios desde el panel administrativo |
| Módulo       | Administración de Usuarios                       |
| Prioridad    | Alta                                             |
| Estado       | Definida                                         |
| RF asociados | RF26                                             |

---

## Historia

Como administrador, requiero gestionar las cuentas registradas en la plataforma para mantener el control y cumplimiento de las políticas de uso.

---

## Criterios de aceptación

### CA-025.1 — Consulta de usuarios

**Dado que** existen cuentas registradas,

**Cuando** el administrador accede al módulo de usuarios,

**Entonces** el sistema deberá mostrar el listado correspondiente.

---

### CA-025.2 — Búsqueda de cuentas

**Dado que** el administrador necesita localizar una cuenta específica,

**Cuando** utiliza los mecanismos de búsqueda,

**Entonces** el sistema deberá mostrar los resultados coincidentes.

---

### CA-025.3 — Bloqueo de cuentas

**Dado que** una cuenta incumple las políticas establecidas,

**Cuando** el administrador ejecuta la acción de bloqueo,

**Entonces** el sistema deberá restringir el acceso a dicha cuenta.

---

### CA-025.4 — Reactivación de cuentas

**Dado que** una cuenta previamente bloqueada puede ser habilitada nuevamente,

**Cuando** el administrador autoriza su reactivación,

**Entonces** el sistema deberá restablecer el acceso correspondiente.

---

### CA-025.5 — Registro de acciones administrativas

**Dado que** el administrador ejecuta una operación sobre una cuenta,

**Cuando** la acción es completada,

**Entonces** el sistema deberá registrar la actividad realizada para fines de auditoría.
