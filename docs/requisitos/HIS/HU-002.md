# HU-002 Publicar libros en la plataforma

---

## Identificación

| Campo        | Valor                            |
| ------------ | -------------------------------- |
| ID           | HU-002                           |
| Título       | Publicar libros en la plataforma |
| Módulo       | Gestión de Publicaciones         |
| Prioridad    | Alta                             |
| Estado       | Definida                         |
| RF asociados | RF05                             |

---

## Historia

Como negocio, requiero registrar publicaciones de libros mediante el ingreso de información descriptiva y comercial para que estas se encuentren disponibles dentro del catálogo de la plataforma.

---

## Criterios de aceptación

### CA-002.1 — Acceso al formulario de publicación

**Dado que** el negocio dispone de una cuenta autenticada,

**Cuando** accede a la funcionalidad de publicación de libros,

**Entonces** el sistema deberá presentar el formulario de registro correspondiente.

---

### CA-002.2 — Registro de publicación

**Dado que** el negocio diligencia la información requerida del libro,

**Cuando** envía el formulario de publicación,

**Entonces** el sistema deberá almacenar la información y crear el registro de la publicación.

---

### CA-002.3 — Validación de campos obligatorios

**Dado que** el negocio se encuentra registrando una publicación,

**Cuando** alguno de los campos obligatorios no contenga información válida,

**Entonces** el sistema deberá impedir el registro y notificar la inconsistencia detectada.

---

### CA-002.4 — Persistencia de información

**Dado que** la publicación cumple las validaciones establecidas,

**Cuando** el sistema procesa la solicitud,

**Entonces** deberá almacenar título, autor, categoría, descripción y precio del libro.

---

### CA-002.5 — Publicación en catálogo

**Dado que** la publicación fue registrada exitosamente,

**Cuando** finaliza el proceso de almacenamiento,

**Entonces** el sistema deberá incorporar automáticamente el libro al catálogo disponible para consulta.

---

### CA-002.6 — Confirmación de operación

**Dado que** la publicación fue creada correctamente,

**Cuando** el sistema complete el proceso de registro,

**Entonces** deberá notificar al negocio que la publicación fue realizada con éxito.

---

### CA-002.7 — Gestión de errores

**Dado que** ocurre una falla durante el proceso de publicación,

**Cuando** el sistema no pueda completar la operación,

**Entonces** deberá informar el error y evitar la creación de registros inconsistentes.
