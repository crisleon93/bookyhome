# HU-013 Recibir notificaciones de mensajes

## Identificación

| Campo        | Valor                              |
| ------------ | ---------------------------------- |
| ID           | HU-013                             |
| Título       | Recibir notificaciones de mensajes |
| Módulo       | Mensajería                         |
| Prioridad    | Alta                               |
| Estado       | Definida                           |
| RF asociados | RF12                               |

---

## Historia

Como negocio, requiero recibir notificaciones cuando un usuario envíe un mensaje para gestionar oportunamente las interacciones asociadas a mis publicaciones.

---

## Criterios de aceptación

### CA-013.1 — Generación de notificación

**Dado que** un usuario envía un mensaje,

**Cuando** el sistema registra la interacción,

**Entonces** deberá generar una notificación para el negocio.

### CA-013.2 — Información de la notificación

**Dado que** existe una nueva notificación,

**Cuando** el negocio la consulta,

**Entonces** deberá visualizar remitente y publicación asociada.

### CA-013.3 — Acceso a conversación

**Dado que** el negocio recibe una notificación,

**Cuando** la selecciona,

**Entonces** el sistema deberá abrir la conversación correspondiente.
