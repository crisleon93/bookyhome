# HU-012 Visualizar ficha detallada de libro

## Identificación

| Campo        | Valor                               |
| ------------ | ----------------------------------- |
| ID           | HU-012                              |
| Título       | Visualizar ficha detallada de libro |
| Módulo       | Catálogo                            |
| Prioridad    | Alta                                |
| Estado       | Definida                            |
| RF asociados | RF10                                |

---

## Historia

Como usuario, requiero consultar la información detallada de una publicación para conocer sus características antes de realizar una interacción o proceso de compra.

---

## Criterios de aceptación

### CA-012.1 — Acceso a la ficha

**Dado que** el usuario visualiza una publicación en el catálogo,

**Cuando** selecciona el libro,

**Entonces** el sistema deberá mostrar la ficha detallada correspondiente.

### CA-012.2 — Información completa

**Dado que** existe una publicación registrada,

**Cuando** se visualiza la ficha detallada,

**Entonces** deberá mostrarse título, autor, categoría, descripción, precio y disponibilidad.

### CA-012.3 — Contacto con vendedor

**Dado que** el usuario consulta la ficha de un libro,

**Cuando** selecciona la opción de contacto,

**Entonces** el sistema deberá habilitar la comunicación con el vendedor.

### CA-012.4 — Consistencia de datos

**Dado que** una publicación fue actualizada,

**Cuando** se consulta la ficha detallada,

**Entonces** la información mostrada deberá corresponder a la última versión registrada.
