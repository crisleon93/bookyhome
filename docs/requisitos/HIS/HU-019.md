# HU-019 Gestionar stock de libros

## Identificación

| Campo        | Valor                     |
| ------------ | ------------------------- |
| ID           | HU-019                    |
| Título       | Gestionar stock de libros |
| Módulo       | Inventario                |
| Prioridad    | Alta                      |
| Estado       | Definida                  |
| RF asociados | RF20                      |

---

## Historia

Como negocio, requiero administrar la cantidad disponible de libros para mantener actualizada la información de inventario.

---

## Criterios de aceptación

### CA-019.1 — Registro de stock

**Dado que** el negocio publica un libro,

**Cuando** define la cantidad disponible,

**Entonces** el sistema deberá almacenar el valor registrado.

### CA-019.2 — Actualización automática

**Dado que** ocurre una venta,

**Cuando** la transacción es confirmada,

**Entonces** el sistema deberá actualizar el stock disponible.

### CA-019.3 — Notificación de agotado

**Dado que** la cantidad disponible alcanza cero,

**Cuando** el sistema actualiza el inventario,

**Entonces** deberá informar que el libro no se encuentra disponible.
