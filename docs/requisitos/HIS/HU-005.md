# HU-005 Comunicarse con el vendedor

---

## Identificación

| Campo        | Valor                       |
| ------------ | --------------------------- |
| ID           | HU-005                      |
| Título       | Comunicarse con el vendedor |
| Módulo       | Mensajería y Comunicación   |
| Prioridad    | Alta                        |
| Estado       | Definida                    |
| RF asociados | RF11                        |

---

## Historia

Como usuario, requiero comunicarme con el vendedor de una publicación para coordinar aspectos relacionados con la adquisición, entrega o consulta de un libro disponible en la plataforma.

---

## Criterios de aceptación

### CA-005.1 — Acceso a la comunicación

**Dado que** el usuario se encuentra visualizando la ficha de un libro,

**Cuando** selecciona la opción de contacto con el vendedor,

**Entonces** el sistema deberá habilitar un canal de comunicación asociado a la publicación.

---

### CA-005.2 — Envío de mensaje

**Dado que** existe un canal de comunicación disponible,

**Cuando** el usuario redacta y envía un mensaje,

**Entonces** el sistema deberá registrar y entregar el mensaje al vendedor correspondiente.

---

### CA-005.3 — Recepción de notificación

**Dado que** el usuario ha enviado un mensaje correctamente,

**Cuando** el sistema registra la comunicación,

**Entonces** el vendedor deberá recibir una notificación indicando la existencia de un nuevo mensaje.

---

### CA-005.4 — Consulta de conversación

**Dado que** existe una conversación entre el usuario y el vendedor,

**Cuando** cualquiera de las partes accede al historial de mensajes,

**Entonces** el sistema deberá mostrar los mensajes asociados a dicha conversación.

---

### CA-005.5 — Registro de historial

**Dado que** se intercambian mensajes dentro de la plataforma,

**Cuando** el sistema procesa cada interacción,

**Entonces** deberá almacenar la información necesaria para mantener el historial de conversación.

---

### CA-005.6 — Asociación con la publicación

**Dado que** una conversación se origina desde una publicación específica,

**Cuando** el sistema registra los mensajes,

**Entonces** deberá asociar la conversación al libro correspondiente.

---

### CA-005.7 — Privacidad de la comunicación

**Dado que** existen conversaciones registradas en la plataforma,

**Cuando** un usuario intenta acceder a una conversación ajena,

**Entonces** el sistema deberá restringir el acceso y proteger la información almacenada.

---

### CA-005.8 — Confirmación de envío

**Dado que** el mensaje fue procesado correctamente,

**Cuando** finaliza la operación de envío,

**Entonces** el sistema deberá informar al usuario que la comunicación fue registrada exitosamente.
