# HU-041 Consultar historial de compras

## Identificacion

| Campo | Valor |
|---|---|
| ID | HU-041 |
| Titulo | Consultar historial de compras |
| Modulo | Compras |
| Prioridad | Media |
| Estado | Definida |
| RF asociados | RF23 |

## Historia

Como usuario, requiero consultar mis compras anteriores para revisar los libros adquiridos y sus datos de compra.

## Criterios de aceptacion

### CA-041.1 — Consulta del historial

**Dado que** el usuario ha realizado compras,

**Cuando** accede a su historial,

**Entonces** el sistema debe mostrar sus compras ordenadas cronologicamente.

### CA-041.2 — Privacidad del historial

**Dado que** el usuario consulta el historial,

**Cuando** solicita la informacion,

**Entonces** el sistema solo debe mostrar las compras asociadas a su cuenta.
