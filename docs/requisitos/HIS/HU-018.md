# HU-018 Guardar historial de interacción

| Módulo       | Historial                        |
| Prioridad    | Media                            |
| Estado       | Definida                         |
| RF asociados | RF19                             |

---

## Historia

Como usuario, requiero consultar el historial de mis interacciones para acceder a información relacionada con publicaciones visualizadas y comunicaciones realizadas.

---

## Criterios de aceptación

### CA-018.1 — Registro de visualizaciones

**Dado que** el usuario consulta una publicación,

**Cuando** finaliza la visualización,

**Entonces** el sistema deberá registrar la interacción.

### CA-018.2 — Registro de mensajes

**Dado que** el usuario envía mensajes,

**Cuando** la operación es completada,

**Entonces** el sistema deberá almacenarlos en el historial.

### CA-018.3 — Consulta de historial

**Dado que** existe información registrada,

**Cuando** el usuario accede a su historial,

**Entonces** el sistema deberá mostrar las interacciones almacenadas.
