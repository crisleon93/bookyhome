# HU-039 Cerrar sesion

## Identificacion

| Campo | Valor |
|---|---|
| ID | HU-039 |
| Titulo | Cerrar sesion |
| Modulo | Autenticacion |
| Prioridad | Media |
| Estado | Definida |
| RF asociados | RF04 |

## Historia

Como usuario autenticado, requiero cerrar mi sesion manualmente para proteger mi cuenta cuando termino de utilizar la plataforma.

## Criterios de aceptacion

### CA-039.1 — Cierre de sesion

**Dado que** el usuario tiene una sesion activa,

**Cuando** selecciona cerrar sesion,

**Entonces** el sistema debe finalizar la sesion en el dispositivo actual.
