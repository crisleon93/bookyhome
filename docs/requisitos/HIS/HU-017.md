# HU-017 Calificar libros

## Identificación

| Campo        | Valor            |
| ------------ | ---------------- |
| ID           | HU-017           |
| Título       | Calificar libros |
| Módulo       | Valoraciones     |
| Prioridad    | Media            |
| Estado       | Definida         |
| RF asociados | RF17             |

---

## Historia

Como usuario, requiero asignar una calificación a los libros publicados para contribuir a la valoración general de las publicaciones.

---

## Criterios de aceptación

### CA-017.1 — Asignación de calificación

**Dado que** el usuario accede a una publicación,

**Cuando** selecciona una valoración entre 1 y 5 estrellas,

**Entonces** el sistema deberá registrar la calificación.

### CA-017.2 — Almacenamiento

**Dado que** se registra una valoración,

**Cuando** el sistema procesa la solicitud,

**Entonces** deberá almacenar la información.

### CA-017.3 — Promedio

**Dado que** existen valoraciones registradas,

**Cuando** se consulta la publicación,

**Entonces** deberá mostrarse el promedio calculado.
