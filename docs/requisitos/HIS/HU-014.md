# HU-014 Gestionar perfil de usuario

| Título       | Gestionar perfil de usuario |
| Módulo       | Gestión de Perfil           |

| Estado       | Definida                    |
| RF asociados | RF13                        |

---

## Historia

Como usuario, requiero administrar la información de mi perfil para mantener actualizados mis datos personales dentro de la plataforma.

---

## Criterios de aceptación

### CA-014.1 — Modificación de datos

**Dado que** el usuario accede a su perfil,

**Cuando** actualiza nombre, teléfono o dirección,

**Entonces** el sistema deberá permitir la modificación.

### CA-014.2 — Validación de información

**Dado que** el usuario realiza cambios,

**Cuando** envía la actualización,

**Entonces** el sistema deberá validar los datos ingresados.

### CA-014.3 — Confirmación

**Dado que** la actualización fue exitosa,

**Cuando** finaliza el proceso,

**Entonces** el sistema deberá notificar que los cambios fueron registrados.
