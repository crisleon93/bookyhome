# HU-027 Compartir publicaciones en redes sociales

---

## Identificación

| Campo        | Valor                                     |
| ------------ | ----------------------------------------- |
| ID           | HU-027                                    |
| Título       | Compartir publicaciones en redes sociales |
| Módulo       | Difusión de Contenido                     |
| Prioridad    | Media                                     |
| Estado       | Definida                                  |
| RF asociados | RF28                                      |

---

## Historia

Como usuario, requiero compartir publicaciones de libros mediante redes sociales o enlaces directos para difundir contenido de interés.

---

## Criterios de aceptación

### CA-027.1 — Acceso a opciones de compartir

**Dado que** el usuario visualiza una publicación,

**Cuando** selecciona la opción de compartir,

**Entonces** el sistema deberá mostrar los mecanismos disponibles.

---

### CA-027.2 — Generación de enlace

**Dado que** el usuario desea compartir una publicación,

**Cuando** selecciona una opción de difusión,

**Entonces** el sistema deberá generar un enlace válido asociado al libro.

---

### CA-027.3 — Acceso desde enlace compartido

**Dado que** existe un enlace generado correctamente,

**Cuando** otro usuario accede mediante dicho enlace,

**Entonces** el sistema deberá mostrar la publicación correspondiente.

---

### CA-027.4 — Integridad de la información

**Dado que** una publicación es compartida,

**Cuando** se consulta desde el enlace generado,

**Entonces** la información presentada deberá coincidir con la publicación original.
