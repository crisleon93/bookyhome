# HU-026 Recibir recomendaciones personalizadas

---

## Identificación

| Campo        | Valor                                  |
| ------------ | -------------------------------------- |
| ID           | HU-026                                 |
| Título       | Recibir recomendaciones personalizadas |
| Módulo       | Recomendaciones                        |
| Prioridad    | Media                                  |
| Estado       | Definida                               |
| RF asociados | RF27                                   |

---

## Historia

Como usuario, requiero recibir recomendaciones personalizadas de libros para descubrir publicaciones relacionadas con mis intereses y actividades dentro de la plataforma.

---

## Criterios de aceptación

### CA-026.1 — Generación de recomendaciones

**Dado que** el usuario posee actividad registrada en la plataforma,

**Cuando** el sistema procesa la información disponible,

**Entonces** deberá generar recomendaciones acordes a los intereses identificados.

---

### CA-026.2 — Visualización de sugerencias

**Dado que** existen recomendaciones disponibles,

**Cuando** el usuario accede a la plataforma,

**Entonces** el sistema deberá mostrar las publicaciones sugeridas.

---

### CA-026.3 — Actualización de recomendaciones

**Dado que** el usuario realiza nuevas interacciones,

**Cuando** el sistema actualiza la información analizada,

**Entonces** deberá recalcular las recomendaciones disponibles.

---

### CA-026.4 — Recomendaciones sin historial

**Dado que** el usuario no posee actividad suficiente,

**Cuando** el sistema intenta generar recomendaciones,

**Entonces** deberá mostrar sugerencias generales basadas en publicaciones destacadas.
