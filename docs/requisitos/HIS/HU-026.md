## Historia

Como usuario nuevo o sin actividad suficiente, requiero recibir sugerencias generales de libros para descubrir publicaciones relevantes en la plataforma.

---

## Criterios de aceptación

### CA-026.1 — Sugerencias sin historial

**Dado que** el usuario no posee historial de actividad suficiente,

**Cuando** el sistema procesa la información disponible,

**Entonces** deberá mostrar sugerencias generales basadas en publicaciones destacadas o populares.

---

### CA-026.2 — Visualización de sugerencias generales

**Dado que** existen recomendaciones disponibles,

**Cuando** el usuario consulta la seccion de recomendaciones,

**Entonces** el sistema deberá mostrar las publicaciones sugeridas.
