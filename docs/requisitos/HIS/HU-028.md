# HU-028 Consultar estadísticas de ventas

---

## Identificación

| Campo        | Valor                            |
| ------------ | -------------------------------- |
| ID           | HU-028                           |
| Título       | Consultar estadísticas de ventas |
| Módulo       | Analítica y Reportes             |
| Prioridad    | Media                            |
| Estado       | Definida                         |
| RF asociados | RF29                             |

---

## Historia

Como negocio, requiero consultar estadísticas relacionadas con ventas e interacciones para evaluar el desempeño de mis publicaciones.

---

## Criterios de aceptación

### CA-028.1 — Consulta de indicadores

**Dado que** existen publicaciones asociadas al negocio,

**Cuando** accede al módulo de estadísticas,

**Entonces** el sistema deberá mostrar los indicadores disponibles.

---

### CA-028.2 — Visualización de ventas

**Dado que** existen transacciones registradas,

**Cuando** el negocio consulta las métricas,

**Entonces** deberá visualizar información relacionada con ventas realizadas.

---

### CA-028.3 — Visualización de interacciones

**Dado que** existen registros de actividad sobre las publicaciones,

**Cuando** el negocio consulta las estadísticas,

**Entonces** el sistema deberá mostrar información de visitas y valoraciones.

---

### CA-028.4 — Actualización de datos

**Dado que** se registran nuevas transacciones o interacciones,

**Cuando** el sistema actualiza las métricas,

**Entonces** las estadísticas deberán reflejar la información más reciente.
