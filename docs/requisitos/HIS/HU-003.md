# HU-003 Buscar libros por título o autor

---

## Identificación

| Campo        | Valor                            |
| ------------ | -------------------------------- |
| ID           | HU-003                           |
| Título       | Buscar libros por título o autor |
| Módulo       | Catálogo y Búsqueda              |
| Prioridad    | Alta                             |
| Estado       | Definida                         |
| RF asociados | RF07                             |

---

## Historia

Como usuario, requiero realizar búsquedas de libros mediante criterios de título o autor para localizar publicaciones registradas dentro de la plataforma.

---

## Criterios de aceptación

### CA-003.1 — Disponibilidad de búsqueda

**Dado que** el usuario accede al catálogo de libros,

**Cuando** visualiza la interfaz de consulta,

**Entonces** el sistema deberá mostrar un campo de búsqueda disponible para ingresar criterios.

---

### CA-003.2 — Búsqueda por título

**Dado que** existen publicaciones registradas en la plataforma,

**Cuando** el usuario ingresa un título completo o parcial,

**Entonces** el sistema deberá recuperar y mostrar las publicaciones que coincidan con el criterio especificado.

---

### CA-003.3 — Búsqueda por autor

**Dado que** existen publicaciones asociadas a diferentes autores,

**Cuando** el usuario ingresa un nombre de autor completo o parcial,

**Entonces** el sistema deberá mostrar los libros relacionados con dicho autor.

---

### CA-003.4 — Visualización de resultados

**Dado que** la búsqueda retorna coincidencias,

**Cuando** el sistema procesa la consulta,

**Entonces** deberá mostrar una lista de resultados con la información básica de cada publicación.

---

### CA-003.5 — Ausencia de coincidencias

**Dado que** el usuario realiza una búsqueda válida,

**Cuando** no existan registros que cumplan el criterio ingresado,

**Entonces** el sistema deberá informar que no se encontraron resultados.

---

### CA-003.6 — Actualización de resultados

**Dado que** el usuario modifica los términos de búsqueda,

**Cuando** ejecuta una nueva consulta,

**Entonces** el sistema deberá actualizar los resultados de acuerdo con los nuevos criterios.

---

### CA-003.7 — Acceso a información detallada

**Dado que** la búsqueda retorna uno o más resultados,

**Cuando** el usuario selecciona una publicación,

**Entonces** el sistema deberá permitir el acceso a la ficha detallada del libro.
