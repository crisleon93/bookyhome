# HU-037 Iniciar sesion

## Identificacion

| Campo | Valor |
|---|---|
| ID | HU-037 |
| Titulo | Iniciar sesion |
| Modulo | Autenticacion |
| Prioridad | Alta |
| Estado | Definida |
| RF asociados | RF02 |

## Historia

Como usuario registrado, requiero iniciar sesion con mi correo y contrasena para acceder a mi cuenta.

## Criterios de aceptacion

### CA-037.1 — Acceso valido

**Dado que** el usuario tiene una cuenta activa,

**Cuando** ingresa credenciales correctas,

**Entonces** el sistema debe iniciar su sesion.

### CA-037.2 — Credenciales invalidas

**Dado que** el usuario ingresa credenciales incorrectas,

**Cuando** solicita iniciar sesion,

**Entonces** el sistema debe rechazar el acceso e informar el error.

### CA-037.3 — Correo sin verificar

**Dado que** la cuenta aun no ha verificado su correo,

**Cuando** el usuario intenta iniciar sesion,

**Entonces** el sistema debe impedir el acceso hasta completar la verificacion.
