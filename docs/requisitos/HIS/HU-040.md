# HU-040 Administrar categorias

## Identificacion

| Campo | Valor |
|---|---|
| ID | HU-040 |
| Titulo | Administrar categorias |
| Modulo | Catalogo |
| Prioridad | Media |
| Estado | Definida |
| RF asociados | RF18 |

## Historia

Como administrador, requiero crear, actualizar y eliminar categorias para mantener organizado el catalogo de libros.

## Criterios de aceptacion

### CA-040.1 — Crear categoria

**Dado que** el administrador ingresa el nombre de una categoria,

**Cuando** confirma la creacion,

**Entonces** el sistema debe validar y registrar la categoria.

### CA-040.2 — Actualizar o eliminar categoria

**Dado que** existe una categoria,

**Cuando** el administrador la actualiza o elimina,

**Entonces** el sistema debe aplicar el cambio si la operacion es valida.
