# HU-011 Visualizar catálogo de libros

---

## Identificación

| Campo        | Valor                         |
| ------------ | ----------------------------- |
| ID           | HU-011                        |
| Título       | Visualizar catálogo de libros |
| Módulo       | Catálogo                      |
| Prioridad    | Alta                          |
| Estado       | Definida                      |
| RF asociados | RF09                          |

---

## Historia

Como usuario, requiero visualizar el catálogo de libros disponibles en la plataforma para consultar las publicaciones registradas y acceder a su información general.

---

## Criterios de aceptación

### CA-011.1 — Acceso al catálogo

**Dado que** el usuario accede a la plataforma,

**Cuando** selecciona la opción de catálogo,

**Entonces** el sistema deberá mostrar las publicaciones disponibles.

---

### CA-011.2 — Visualización de información básica

**Dado que** existen libros registrados en la plataforma,

**Cuando** el catálogo es cargado,

**Entonces** el sistema deberá mostrar como mínimo el título, autor y categoría de cada publicación.

---

### CA-011.3 — Actualización automática

**Dado que** se registra una modificación en las publicaciones disponibles,

**Cuando** el sistema actualiza la información del catálogo,

**Entonces** deberá reflejar los cambios realizados sin requerir intervención manual.

---

### CA-011.4 — Navegación entre publicaciones

**Dado que** el usuario visualiza el catálogo,

**Cuando** consulta las publicaciones disponibles,

**Entonces** deberá poder navegar entre los diferentes registros mostrados.

---

### CA-011.5 — Acceso a detalle de libro

**Dado que** una publicación se encuentra visible en el catálogo,

**Cuando** el usuario selecciona el libro,

**Entonces** el sistema deberá permitir el acceso a su ficha detallada.

---

### CA-011.6 — Disponibilidad de resultados

**Dado que** existen publicaciones activas en la plataforma,

**Cuando** el usuario consulta el catálogo,

**Entonces** el sistema deberá presentar todos los registros disponibles de acuerdo con los criterios vigentes.

---

### CA-011.7 — Catálogo sin publicaciones

**Dado que** no existen publicaciones disponibles,

**Cuando** el usuario accede al catálogo,

**Entonces** el sistema deberá informar que no se encontraron libros registrados.

---

### CA-011.8 — Consistencia de información

**Dado que** una publicación aparece en el catálogo,

**Cuando** el usuario consulta sus datos básicos,

**Entonces** la información presentada deberá coincidir con los datos almacenados en el sistema.
