# HU-010 Gestionar publicaciones de libros

---

## Identificación

| Campo        | Valor                             |
| ------------ | --------------------------------- |
| ID           | HU-010                            |
| Título       | Gestionar publicaciones de libros |
| Módulo       | Gestión de Publicaciones          |
| Prioridad    | Alta                              |
| Estado       | Definida                          |
| RF asociados | RF06                              |

---

## Historia

Como negocio, requiero administrar las publicaciones de libros registradas en la plataforma para mantener actualizada la información disponible en el catálogo.

---

## Criterios de aceptación

### CA-010.1 — Consulta de publicaciones propias

**Dado que** el negocio posee publicaciones registradas,

**Cuando** accede al módulo de gestión de publicaciones,

**Entonces** el sistema deberá mostrar el listado de libros asociados a su cuenta.

---

### CA-010.2 — Edición de publicación

**Dado que** existe una publicación registrada,

**Cuando** el negocio selecciona la opción de edición y modifica la información permitida,

**Entonces** el sistema deberá habilitar la actualización de los datos del libro.

---

### CA-010.3 — Validación de información actualizada

**Dado que** el negocio realiza modificaciones en una publicación,

**Cuando** envía los cambios para su almacenamiento,

**Entonces** el sistema deberá validar la integridad y obligatoriedad de los datos ingresados.

---

### CA-010.4 — Actualización de publicación

**Dado que** la información modificada cumple las validaciones establecidas,

**Cuando** el sistema procesa la solicitud,

**Entonces** deberá actualizar los datos de la publicación correspondiente.

---

### CA-010.5 — Eliminación de publicación

**Dado que** existe una publicación asociada al negocio,

**Cuando** el negocio solicita eliminarla,

**Entonces** el sistema deberá retirar la publicación del catálogo.

---

### CA-010.6 — Confirmación de eliminación

**Dado que** una publicación fue eliminada correctamente,

**Cuando** finaliza la operación,

**Entonces** el sistema deberá informar la ejecución exitosa de la acción.

---

### CA-010.7 — Reflejo de cambios en el catálogo

**Dado que** una publicación ha sido modificada o eliminada,

**Cuando** el sistema actualiza la información almacenada,

**Entonces** el catálogo deberá reflejar los cambios realizados sin inconsistencias.

---

### CA-010.8 — Confirmación de actualización

**Dado que** una modificación fue almacenada correctamente,

**Cuando** finaliza el proceso de actualización,

**Entonces** el sistema deberá notificar al negocio que los cambios fueron registrados exitosamente.
