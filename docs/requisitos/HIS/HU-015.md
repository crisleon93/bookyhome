# HU-015 Gestionar perfil de negocio

| ID           | HU-015                      |
| Título       | Gestionar perfil de negocio |
| Módulo       | Gestión de Perfil           |

| Estado       | Definida                    |
| RF asociados | RF14                        |

---

## Historia

Como negocio, requiero administrar la información de mi perfil comercial para mantener actualizados los datos visibles para los usuarios.

---

## Criterios de aceptación

### CA-015.1 — Edición de perfil

**Dado que** el negocio accede a su perfil,

**Cuando** modifica la información permitida,

**Entonces** el sistema deberá permitir la actualización.

### CA-015.2 — Validación

**Dado que** se realizan cambios,

**Cuando** son enviados al sistema,

**Entonces** deberán validarse antes de almacenarse.

### CA-015.3 — Confirmación

**Dado que** la actualización fue exitosa,

**Cuando** finaliza la operación,

**Entonces** el sistema deberá notificar el resultado.
