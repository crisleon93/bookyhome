# HU-034 Utilizar carrito de compras

---

| ID           | HU-034                      |
| Título       | Utilizar carrito de compras |
| Módulo       | Compras                     |
| Prioridad    | Alta                        |
| Estado       | Definida                    |
| RF asociados | RF34                        |

---

## Historia

Como usuario, requiero gestionar un carrito de compras para agrupar libros antes de completar el proceso de pago.

---

## Criterios de aceptación

### CA-034.1 — Agregar libros al carrito

**Dado que** el usuario visualiza una publicación disponible,

**Cuando** selecciona la opción de agregar al carrito,

**Entonces** el sistema deberá incorporar el libro a la lista de compra.

---

### CA-034.2 — Visualización del carrito

**Dado que** existen libros agregados,

**Cuando** el usuario accede al carrito,

**Entonces** el sistema deberá mostrar los productos seleccionados.

---

### CA-034.3 — Eliminación de productos

**Dado que** existe un libro registrado en el carrito,

**Cuando** el usuario decide retirarlo,

**Entonces** el sistema deberá actualizar la lista de compra.

---

### CA-034.4 — Cálculo de valores

**Dado que** existen productos agregados al carrito,

**Cuando** el sistema muestra el resumen de compra,

**Entonces** deberá calcular y presentar el valor total correspondiente.

---

### CA-034.5 — Conservación temporal

**Dado que** el usuario mantiene una sesión activa,

**Cuando** abandona temporalmente el proceso de compra,

**Entonces** el sistema deberá conservar el contenido del carrito hasta que se complete o cancele la operación.
