# HU-029 Acceder desde múltiples dispositivos

---

## Identificación

| Campo        | Valor                                |
| ------------ | ------------------------------------ |
| ID           | HU-029                               |
| Título       | Acceder desde múltiples dispositivos |
| Módulo       | Gestión de Acceso                    |
| Prioridad    | Media                                |
| Estado       | Definida                             |
| RF asociados | RF30                                 |

---

## Historia

Como usuario, requiero acceder a la plataforma desde diferentes dispositivos para utilizar mis funcionalidades sin restricciones de equipo o ubicación.

---

## Criterios de aceptación

### CA-029.1 — Inicio de sesión

**Dado que** el usuario posee credenciales válidas,

**Cuando** accede desde un dispositivo compatible,

**Entonces** el sistema deberá permitir la autenticación.

---

### CA-029.2 — Disponibilidad de información

**Dado que** el usuario inicia sesión correctamente,

**Cuando** accede a sus funcionalidades,

**Entonces** deberá visualizar su información registrada.

---

### CA-029.3 — Consistencia de datos

**Dado que** el usuario utiliza distintos dispositivos,

**Cuando** consulta su información,

**Entonces** los datos deberán mantenerse consistentes entre sesiones.

---

### CA-029.4 — Seguridad de acceso

**Dado que** se detecta un intento de acceso,

**Cuando** el sistema valida las credenciales,

**Entonces** deberá aplicar los controles de seguridad establecidos.
