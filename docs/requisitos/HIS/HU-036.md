# HU-036 Registrar actividad de la plataforma

---

| ID           | HU-036                                     |

| Modulo       | Auditoria                                  |
| Prioridad    | Media                                      |
| Estado       | Definida                                   |
| RF asociados | RF-017                                    |

---

## Historia

Como administrador, requiero que el sistema conserve un registro de publicaciones, mensajes y transacciones para mantener la trazabilidad de la actividad de la plataforma.

---

## Criterios de aceptacion

### CA-036.1 — Registro de eventos

**Dado que** se registra una publicacion, se envia un mensaje o se realiza una transaccion,

**Cuando** la operacion se completa,

**Entonces** el sistema debera almacenar un registro de la actividad correspondiente.

---

### CA-036.2 — Datos de trazabilidad

**Dado que** el sistema almacena un evento,

**Cuando** crea el registro de actividad,

**Entonces** debera conservar el tipo de evento, la fecha y hora, y la referencia a la publicacion, mensaje o transaccion relacionada.
