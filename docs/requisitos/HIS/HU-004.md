# HU-004 Filtrar libros por categoría

---

| Campo        | Valor                        |
| ------------ | ---------------------------- |
| ID           | HU-004                       |
| Título       | Filtrar libros por categoría |
| Módulo       | Catálogo y Búsqueda          |
| Prioridad    | Media                        |
| Estado       | Definida                     |
| RF asociados | RF008                        |

---

## Historia

Como usuario, requiero filtrar las publicaciones disponibles por categoría para visualizar únicamente los libros que correspondan a mis criterios de interés.

---

## Criterios de aceptación

### CA-004.1 — Visualización de categorías

**Dado que** el usuario accede al catálogo,

**Cuando** consulta las opciones de filtrado,

**Entonces** el sistema deberá mostrar las categorías disponibles.

---

### CA-004.2 — Aplicación de filtro

**Dado que** existen publicaciones registradas en diferentes categorías,

**Cuando** el usuario selecciona una categoría específica,

**Entonces** el sistema deberá mostrar únicamente las publicaciones asociadas a dicha categoría.

---

### CA-004.3 — Actualización de resultados

**Dado que** el usuario aplica un filtro,

**Cuando** el sistema procesa la selección,

**Entonces** deberá actualizar el catálogo mostrando únicamente los resultados correspondientes.

---

### CA-004.4 — Cambio de categoría

**Dado que** existe un filtro activo,

**Cuando** el usuario selecciona una categoría diferente,

**Entonces** el sistema deberá actualizar los resultados según la nueva selección.

---

### CA-004.5 — Eliminación del filtro

**Dado que** el usuario tiene una categoría aplicada,

**Cuando** elimina el filtro seleccionado,

**Entonces** el sistema deberá mostrar nuevamente el catálogo completo.

---

### CA-004.6 — Categorías sin resultados

**Dado que** una categoría no contiene publicaciones disponibles,

**Cuando** el usuario la selecciona,

**Entonces** el sistema deberá informar que no existen registros asociados a dicha categoría.
