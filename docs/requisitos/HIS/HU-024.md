# HU-024 Moderar contenido publicado

---

## Identificación

| Campo        | Valor                       |
| ------------ | --------------------------- |
| ID           | HU-024                      |
| Título       | Moderar contenido publicado |
| Módulo       | Administración y Moderación |
| Prioridad    | Alta                        |
| Estado       | Definida                    |
| RF asociados | RF25, RF36                  |

---

## Historia

Como administrador, requiero revisar publicaciones reportadas para aplicar acciones de moderación cuando se identifique contenido que incumpla las políticas de la plataforma.

---

## Criterios de aceptación

### CA-024.1 — Consulta de reportes

**Dado que** existen publicaciones reportadas,

**Cuando** el administrador accede al módulo de moderación,

**Entonces** el sistema deberá mostrar los reportes pendientes.

---

### CA-024.2 — Revisión de contenido

**Dado que** una publicación posee reportes asociados,

**Cuando** el administrador consulta su información,

**Entonces** deberá visualizar los detalles necesarios para la evaluación.

---

### CA-024.3 — Aplicación de medidas

**Dado que** se identifica incumplimiento de políticas,

**Cuando** el administrador toma una decisión,

**Entonces** el sistema deberá permitir ocultar o eliminar la publicación.

---

### CA-024.4 — Registro de acciones

**Dado que** se ejecuta una acción de moderación,

**Cuando** la operación finaliza,

**Entonces** el sistema deberá almacenar evidencia de la acción realizada.
