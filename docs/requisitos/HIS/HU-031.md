---

## Historia

Como usuario comprador, requiero que mis reseñas de libros adquiridos en la plataforma se identifiquen como compra verificada para que otros usuarios distingan esas opiniones.

---

## Criterios de aceptación

### CA-031.1 — Validacion de compra

**Dado que** existe una reseña de un libro,

**Cuando** el sistema consulta el historial de compras,

**Entonces** deberá verificar que exista una transacción asociada al libro.

---

### CA-031.2 — Distintivo de compra verificada

**Dado que** existe una reseña asociada a una compra completada,

**Cuando** otros usuarios consultan el libro,

**Entonces** el sistema debera mostrar el distintivo de compra verificada en esa resena.

---

### CA-031.3 — Resena sin compra verificada

**Dado que** una resena no tiene una compra asociada,

**Cuando** otros usuarios consultan el libro,

**Entonces** el sistema no debera mostrar el distintivo de compra verificada.

---
