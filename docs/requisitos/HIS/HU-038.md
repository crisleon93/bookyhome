# HU-038 Recuperar contrasena

## Identificacion

| Campo | Valor |
|---|---|
| ID | HU-038 |
| Titulo | Recuperar contrasena |
| Modulo | Autenticacion |
| Prioridad | Alta |
| Estado | Definida |
| RF asociados | RF03 |

## Historia

Como usuario, requiero recuperar mi contrasena mediante un correo de verificacion para volver a acceder a mi cuenta.

## Criterios de aceptacion

### CA-038.1 — Solicitud de recuperacion

**Dado que** el usuario indica el correo asociado a su cuenta,

**Cuando** solicita recuperar la contrasena,

**Entonces** el sistema debe enviar las instrucciones de recuperacion al correo.

### CA-038.2 — Cambio de contrasena

**Dado que** el usuario cuenta con un enlace de verificacion vigente,

**Cuando** define una nueva contrasena valida,

**Entonces** el sistema debe actualizar sus credenciales.
