# HU-022 Confirmar transacciones

---

## Identificación

| Campo        | Valor                   |
| ------------ | ----------------------- |
| ID           | HU-022                  |
| Título       | Confirmar transacciones |
| Módulo       | Pagos                   |
| Prioridad    | Alta                    |
| Estado       | Definida                |
| RF asociados | RF23                    |

---

## Historia

Como usuario, requiero recibir confirmación de las transacciones realizadas para verificar que el proceso de compra fue completado correctamente.

---

## Criterios de aceptación

### CA-022.1 — Generación de confirmación

**Dado que** una transacción fue aprobada,

**Cuando** finaliza el proceso de pago,

**Entonces** el sistema deberá generar una confirmación de compra.

---

### CA-022.2 — Información de la confirmación

**Dado que** existe una confirmación generada,

**Cuando** el usuario la consulta,

**Entonces** deberá visualizar fecha, valor y método de pago utilizado.

---

### CA-022.3 — Consulta posterior

**Dado que** una transacción fue registrada,

**Cuando** el usuario accede a su historial,

**Entonces** el sistema deberá permitir consultar la confirmación correspondiente.

---

### CA-022.4 — Integridad de la información

**Dado que** se genera una confirmación,

**Cuando** esta es almacenada,

**Entonces** la información deberá coincidir con la transacción registrada.
