# HU-035 Recibir notificaciones de novedades

| Título       | Recibir notificaciones de novedades |
| Módulo       | Notificaciones                      |
| Prioridad    | Media                               |
| Estado       | Definida                            |
| RF asociados | RF35                                |

---

## Historia

Como usuario, requiero recibir notificaciones sobre nuevas publicaciones y novedades relacionadas con mis intereses para mantenerme informado dentro de la plataforma.

---

## Criterios de aceptación

### CA-035.1 — Generación de notificaciones

**Dado que** se registra una nueva publicación o novedad relevante,

**Cuando** el sistema identifica usuarios interesados,

**Entonces** deberá generar las notificaciones correspondientes.

---

### CA-035.2 — Recepción de novedades

**Dado que** existen notificaciones disponibles,

**Cuando** el usuario accede a la plataforma,

**Entonces** deberá visualizar las novedades pendientes.

---

### CA-035.3 — Consulta de información

**Dado que** el usuario recibe una notificación,

**Cuando** la selecciona,

**Entonces** el sistema deberá mostrar el contenido relacionado.

---

### CA-035.4 — Gestión de preferencias

**Dado que** el usuario desea controlar las notificaciones recibidas,

**Cuando** modifica sus preferencias,

**Entonces** el sistema deberá aplicar la configuración establecida.

---

### CA-035.5 — Registro de entrega

**Dado que** una notificación fue generada,

**Cuando** el sistema completa el proceso de envío,

**Entonces** deberá registrar el estado correspondiente para fines de seguimiento.
