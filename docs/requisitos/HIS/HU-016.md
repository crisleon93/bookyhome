# HU-016 Validar disponibilidad de libros

## Identificación

| Campo        | Valor                            |
| ------------ | -------------------------------- |
| ID           | HU-016                           |
| Título       | Validar disponibilidad de libros |
| Módulo       | Inventario                       |
| Prioridad    | Alta                             |
| Estado       | Definida                         |
| RF asociados | RF15                             |

---

## Historia

Como sistema, requiero gestionar y mostrar el estado de disponibilidad de los libros para proporcionar información actualizada a los usuarios.

---

## Criterios de aceptación

### CA-016.1 — Visualización de disponibilidad

**Dado que** existe una publicación activa,

**Cuando** se consulta su información,

**Entonces** el sistema deberá mostrar el estado de disponibilidad.

### CA-016.2 — Actualización de estado

**Dado que** el negocio modifica la disponibilidad,

**Cuando** la información es almacenada,

**Entonces** el sistema deberá actualizar el estado correspondiente.

### CA-016.3 — Consulta por usuario

**Dado que** un usuario visualiza la ficha de un libro,

**Cuando** consulta sus detalles,

**Entonces** deberá visualizar la disponibilidad actual.
