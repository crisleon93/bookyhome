# HU-001 Registrar usuario

---

## Identificación

| Campo        | Valor                                           |
| ------------ | ----------------------------------------------- |
| ID           | HU-001                                          |
| Título       | Registrar usuario con validación y confirmación |
| Módulo       | Autenticación                                   |
| Prioridad    | Alta                                            |
| Estado       | Definida                                        |
| RF asociados | RF01, RF02, RF03 , RF04                         |

---

## Historia

Como usuario, requiero registrar una cuenta en la plataforma mediante el suministro de información personal y credenciales de acceso para utilizar las funcionalidades disponibles del sistema.

---

## Criterios de aceptación

### CA-001.1 — Registro exitoso

**Dado que** el usuario accede al formulario de registro,

**Cuando** diligencia correctamente todos los campos obligatorios,

**Entonces** el sistema deberá crear la cuenta de usuario.

---

### CA-001.2 — Validación de campos obligatorios

**Dado que** el usuario se encuentra realizando el registro,

**Cuando** uno o más campos obligatorios se encuentren vacíos,

**Entonces** el sistema deberá impedir el registro y notificar los campos requeridos.

---

### CA-001.3 — Validación de correo electrónico

**Dado que** el usuario ingresa una dirección de correo electrónico,

**Cuando** el formato del correo no sea válido,

**Entonces** el sistema deberá rechazar la solicitud e informar el error correspondiente.

---

### CA-001.4 — Validación de correo duplicado

**Dado que** existe una cuenta asociada al correo ingresado,

**Cuando** el usuario intenta completar el registro,

**Entonces** el sistema deberá informar que el correo ya se encuentra registrado.

---

### CA-001.5 — Validación de contraseña

**Dado que** el usuario define una contraseña,

**Cuando** esta no cumpla los requisitos de seguridad establecidos,

**Entonces** el sistema deberá impedir el registro e informar las restricciones aplicables.

---

### CA-001.6 — Envío de confirmación

**Dado que** el registro ha sido realizado correctamente,

**Cuando** el sistema finaliza el proceso de creación de cuenta,

**Entonces** deberá enviar un correo electrónico de confirmación al usuario.

---

### CA-001.7 — Activación de cuenta

**Dado que** el usuario no ha confirmado su correo electrónico,

**Cuando** intenta iniciar sesión en la plataforma,

**Entonces** el sistema deberá impedir el acceso hasta completar la verificación.

---

### CA-001.8 — Confirmación visual

**Dado que** el correo de verificación fue enviado correctamente,

**Cuando** finaliza el proceso de registro,

**Entonces** el sistema deberá mostrar el mensaje "Correo de confirmación enviado".
