---

## Historia

Como usuario, requiero comparar diferentes libros de forma simultánea para analizar sus características y facilitar la toma de decisiones.

---

## Criterios de aceptación

### CA-033.1 — Selección de publicaciones

**Dado que** el usuario consulta el catálogo,

**Cuando** selecciona libros para comparar,

**Entonces** el sistema deberá agregarlos al módulo de comparación.

---

### CA-033.3 — Consulta de características

**Dado que** la comparación se encuentra activa,

**Cuando** el usuario analiza los resultados,

**Entonces** deberá visualizar los atributos relevantes de cada publicación.

---

### CA-033.4 — Eliminación de elementos

**Dado que** existe una comparación configurada,

**Cuando** el usuario elimina uno de los libros seleccionados,

**Entonces** el sistema deberá actualizar la comparación correspondiente.
