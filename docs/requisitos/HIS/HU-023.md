# HU-023 Consultar seguimiento de reportes

---

## Identificación

| Campo        | Valor                  |
| ------------ | ---------------------- |
| ID           | HU-023                 |
| Título       | Consultar seguimiento de reportes |
| Módulo       | Moderación                         |
| Prioridad    | Alta                   |
| Estado       | Definida               |
| RF asociados | RF19, RF36              |

---

## Historia

Como usuario que envio un reporte, requiero consultar su estado para conocer el avance de la revision administrativa.

---

## Criterios de aceptación

### CA-023.1 — Consulta del estado

**Dado que** el usuario envio un reporte,

**Cuando** consulta el seguimiento,

**Entonces** el sistema debera mostrar su estado actual.

---

### CA-023.2 — Privacidad del seguimiento

**Dado que** el usuario consulta el seguimiento,

**Cuando** solicita el estado de un reporte,

**Entonces** el sistema solo debera mostrar reportes enviados por ese usuario.

---

### CA-023.3 — Estados disponibles

**Dado que** el reporte se encuentra en seguimiento,

**Cuando** el administrador cambia su estado,

**Entonces** debera utilizar uno de estos estados: Pendiente, En revision, Resuelto o Rechazado.

---

### CA-023.4 — Historial de cambios

**Dado que** el estado de un reporte cambia,

**Cuando** el sistema almacena la actualizacion,

**Entonces** debera conservar el historial de estados para fines de seguimiento y auditoria.
