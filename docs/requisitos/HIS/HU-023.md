# HU-023 Reportar publicaciones

---

## Identificación

| Campo        | Valor                  |
| ------------ | ---------------------- |
| ID           | HU-023                 |
| Título       | Reportar publicaciones |
| Módulo       | Moderación             |
| Prioridad    | Alta                   |
| Estado       | Definida               |
| RF asociados | RF24                   |

---

## Historia

Como usuario, requiero reportar publicaciones que incumplan las políticas de la plataforma para facilitar su revisión por parte de la administración.

---

## Criterios de aceptación

### CA-023.1 — Inicio de reporte

**Dado que** el usuario visualiza una publicación,

**Cuando** selecciona la opción de reportar,

**Entonces** el sistema deberá mostrar el formulario correspondiente.

---

### CA-023.2 — Registro de motivo

**Dado que** el usuario desea reportar contenido,

**Cuando** diligencia el formulario,

**Entonces** deberá seleccionar un motivo válido para el reporte.

---

### CA-023.3 — Envío de reporte

**Dado que** la información requerida fue completada,

**Cuando** el usuario confirma la operación,

**Entonces** el sistema deberá registrar el reporte asociado a la publicación.

---

### CA-023.4 — Disponibilidad para revisión

**Dado que** existe un reporte registrado,

**Cuando** un administrador accede al módulo de moderación,

**Entonces** deberá visualizar la información correspondiente para su análisis.
