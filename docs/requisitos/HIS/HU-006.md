# HU-006 Comentar libros

---

## Identificación

| Campo        | Valor                       |
| ------------ | --------------------------- |
| ID           | HU-006                      |
| Título       | Comentar libros             |
| Módulo       | Comentarios                 |
| Prioridad    | Media                       |
| Estado       | Definida                    |
| RF asociados | RF14                        |

---

## Historia

Como usuario, requiero publicar comentarios sobre los libros disponibles para compartir opiniones utiles con otros usuarios.

---

## Criterios de aceptación

### CA-006.2 — Registro de comentario

**Dado que** el usuario desea compartir una opinión sobre un libro,

**Cuando** ingresa un comentario y confirma su envío,

**Entonces** el sistema deberá almacenar el comentario asociado a la publicación correspondiente.

---

### CA-006.5 — Visualización de comentarios

**Dado que** existen comentarios registrados para una publicación,

**Cuando** un usuario accede a la ficha del libro,

**Entonces** el sistema deberá mostrar los comentarios disponibles.

---

### CA-006.7 — Actualización de valoración

**Dado que** el usuario ha publicado previamente un comentario,

**Cuando** modifica su comentario,

**Entonces** el sistema deberá actualizar el comentario almacenado.

---

### CA-006.8 — Confirmación de comentario

**Dado que** el comentario fue procesado correctamente,

**Cuando** finaliza la operación,

**Entonces** el sistema deberá informar que el comentario fue registrado exitosamente.
