# HU-006 Calificar y comentar libros

---

## Identificación

| Campo        | Valor                       |
| ------------ | --------------------------- |
| ID           | HU-006                      |
| Título       | Calificar y comentar libros |
| Módulo       | Valoraciones y Comentarios  |
| Prioridad    | Media                       |
| Estado       | Definida                    |
| RF asociados | RF17                        |

---

## Historia

Como usuario, requiero registrar calificaciones y comentarios sobre los libros disponibles en la plataforma para compartir mi experiencia y contribuir a la evaluación de las publicaciones por parte de otros usuarios.

---

## Criterios de aceptación

### CA-006.1 — Registro de calificación

**Dado que** el usuario accede a la ficha de un libro,

**Cuando** selecciona una valoración dentro del rango permitido de 1 a 5 estrellas,

**Entonces** el sistema deberá registrar la calificación asociada a la publicación.

---

### CA-006.2 — Registro de comentario

**Dado que** el usuario desea compartir una opinión sobre un libro,

**Cuando** ingresa un comentario y confirma su envío,

**Entonces** el sistema deberá almacenar el comentario asociado a la publicación correspondiente.

---

### CA-006.3 — Validación de rango de calificación

**Dado que** el usuario intenta registrar una valoración,

**Cuando** el valor ingresado se encuentre fuera del rango permitido,

**Entonces** el sistema deberá rechazar la operación e informar la restricción aplicable.

---

### CA-006.4 — Visualización de valoraciones

**Dado que** una publicación posee calificaciones registradas,

**Cuando** un usuario consulta la ficha detallada del libro,

**Entonces** el sistema deberá mostrar las valoraciones asociadas.

---

### CA-006.5 — Visualización de comentarios

**Dado que** existen comentarios registrados para una publicación,

**Cuando** un usuario accede a la ficha del libro,

**Entonces** el sistema deberá mostrar los comentarios disponibles.

---

### CA-006.6 — Moderación de contenido

**Dado que** un usuario envía un comentario,

**Cuando** el contenido incumpla las políticas de uso establecidas,

**Entonces** el sistema deberá impedir su publicación o marcarlo para revisión administrativa.

---

### CA-006.7 — Actualización de valoración

**Dado que** el usuario ha registrado previamente una calificación,

**Cuando** modifica su valoración o comentario,

**Entonces** el sistema deberá actualizar la información almacenada.

---

### CA-006.8 — Confirmación de registro

**Dado que** la calificación y el comentario fueron procesados correctamente,

**Cuando** finaliza la operación,

**Entonces** el sistema deberá informar que la valoración fue registrada exitosamente.
