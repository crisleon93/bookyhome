# HU-032 Registrar opciones de envío

---

## Identificación

| Campo        | Valor                       |
| ------------ | --------------------------- |
| ID           | HU-032                      |
| Título       | Registrar opciones de envío |
| Módulo       | Logística y Entrega         |
| Prioridad    | Media                       |
| Estado       | Definida                    |
| RF asociados | RF32                        |

---

## Historia

Como negocio, requiero configurar opciones de envío para ofrecer alternativas de entrega asociadas a mis publicaciones.

---

## Observaciones

* Las opciones de envío deberán asociarse a publicaciones activas.
* El negocio podrá actualizar la información de entrega.
* El usuario deberá visualizar las alternativas disponibles antes de finalizar una compra.

---

### CA-032.2 — Visualización para usuarios

**Dado que** una publicación posee opciones de envío registradas,

**Cuando** el usuario consulta sus detalles,

**Entonces** deberá visualizar las alternativas disponibles.

---

### CA-032.3 — Actualización de información

**Dado que** el negocio modifica una opción de envío,

**Cuando** guarda los cambios realizados,

**Entonces** el sistema deberá actualizar la información almacenada.

---

### CA-032.4 — Disponibilidad durante la compra

**Dado que** el usuario inicia el proceso de adquisición,

**Cuando** selecciona las condiciones de entrega,

**Entonces** el sistema deberá permitir elegir una de las opciones configuradas.
