# Manual de usuario de BookyHome

## 1. Ingreso a la plataforma

1. Abrir `http://localhost:5173`.
2. Seleccionar **Registrarse** para crear una cuenta o **Iniciar sesion** si ya existe.
3. Completar los datos solicitados.
4. Verificar el correo cuando la plataforma lo solicite.
5. Si se olvida la contrasena, usar la opcion de recuperacion.

## 2. Comprar un libro

1. Entrar al catalogo.
2. Buscar por texto o utilizar los filtros.
3. Abrir el detalle de un libro.
4. Agregar el libro al carrito.
5. Revisar cantidades y datos de envio.
6. Continuar al checkout.
7. Seleccionar el metodo de pago disponible y confirmar el pedido.
8. Consultar el estado desde el historial de pedidos.

## 3. Favoritos y perfil

Los compradores pueden guardar libros en favoritos, administrar sus datos, revisar direcciones, consultar pedidos y gestionar notificaciones desde su panel.

## 4. Funciones del vendedor

Un usuario vendedor puede:

- Registrar y configurar su tienda.
- Publicar libros.
- Editar informacion y stock.
- Gestionar ofertas.
- Revisar pedidos y ventas.
- Consultar metricas y herramientas disponibles.

Para publicar contenido se requiere iniciar sesion con el rol correspondiente.

## 5. Funciones del administrador

El administrador puede acceder al panel protegido para consultar y gestionar usuarios, libros, tiendas, ordenes, finanzas, quejas y soporte.

## 6. Quejas y soporte

Desde las opciones disponibles, el usuario puede registrar una solicitud, adjuntar evidencia cuando corresponda y consultar la respuesta o el estado del caso.

## 7. App movil

La app movil se ejecuta con Expo desde `app-movil/` y consume la API del backend. Para probarla en un celular, el dispositivo y el computador deben estar en la misma red WiFi y la URL de la API debe usar la IP local del computador, no `localhost`.

## 8. Recomendaciones

- No compartir contrasenas ni tokens.
- Verificar los datos del pedido antes de confirmar.
- Usar imagenes y descripciones correctas al publicar libros.
- Cerrar sesion en equipos compartidos.
- Reportar errores mediante el canal de soporte definido por el equipo.
