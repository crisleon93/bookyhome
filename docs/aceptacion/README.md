# Evidencias de aceptacion

Esta carpeta contiene los documentos relacionados con las pruebas de aceptacion de BookyHome.

## Archivos

- `Plantilla_Caso_de_prueba.xlsx`: matriz de casos de prueba con descripcion, fecha, datos de entrada, resultado esperado, resultado obtenido, estado y capturas.

La matriz incluye pruebas de registro, inicio de sesion, publicacion de libros, busqueda, filtros, detalle, carrito y checkout.

## Uso de la matriz

1. Abrir el archivo con Microsoft Excel o una aplicacion compatible.
2. Revisar que cada caso tenga resultado esperado y resultado obtenido.
3. Mantener actualizado el estado de cada caso.
4. Adjuntar capturas cuando el caso lo requiera.
5. Registrar los casos ejecutados con el usuario final durante la aceptacion.

La matriz sirve como evidencia de pruebas, pero el criterio 6 tambien requiere capacitacion y acta formal de entrega.
